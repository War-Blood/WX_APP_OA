# 05-ui-ux — UI/UX 设计

> 维度：视觉与交互（设计令牌、线框图、组件复用、交互流程）
> 读者：前端开发、设计师、产品
> 上游依赖：`01-requirements.md`、OA 现有设计系统
> 下游影响：前端代码实现（小程序 + Webapp）

## 文档目标

定义工作日报的视觉与交互规格。**视觉方向复用 OA 现有设计系统**（主色 #2B6DE8、卡片式、分段 Tab），工作日报以绿色状态标识区分于公出日志；不重新设计。

## 0. 视觉方向

> 视觉方向复用 OA 现有设计系统（`frontend-design` 已确立），本次不重做视觉。

- **风格关键词**：简洁、移动优先、分段 Tab、卡片式、状态色区分
- **配色策略**：主色 #2B6DE8 用于 Tab 选中态与主按钮；工作日报状态用绿色（success #22C55E）标签区分于公出（蓝）与补公出（黄）
- **字体策略**：沿用 OA 系统字体（默认字体栈），数字/日期等宽对齐
- **布局策略**：Flex-First，卡片间距 24rpx，表单字段纵向排列
- **签名元素**：工作日报 Tab 用绿色标签「工作日报」；写日报页顶部三段日志类型 Tab 栏

## 2. 小程序端设计

### 2.1 写日报页（report-edit）— 工作日报 Tab

**页面路径**：`pages/employee/report-edit/index`

**ASCII 线框图：**

```
┌─────────────────────────────────────┐
│  [<] 写日报               [保存草稿] │  ← NavBar
├─────────────────────────────────────┤
│  ┌───────────────────────────────┐  │
│  │ 公出日志 │ 补公出日志 │工作日报│  │  ← type-tab-bar（三段 Tab）
│  └───────────────────────────────┘  │
│  ┌─────────────────────────────┐   │
│  │ 填写日期    [2026-08-05  ▾]  │   │  ← Card
│  └─────────────────────────────┘   │
│  ┌─────────────────────────────┐   │
│  │ 今日工作                      │   │
│  │ [ 今日工作内容(必填)…… ]      │   │  ← textarea 2000字
│  │ 0/2000                        │   │
│  └─────────────────────────────┘   │
│  ┌─────────────────────────────┐   │
│  │ 计划与问题                    │   │
│  │ 明日工作计划 [……]            │   │
│  │ 遇到的问题   [……选填]        │   │
│  │ 需协调事项   [……选填]        │   │
│  └─────────────────────────────┘   │
│                                     │
│  [          提交工作日报          ]  │  ← 主按钮
└─────────────────────────────────────┘
```

**元素说明：**

| 元素 | 组件 | 尺寸 | 说明 |
|------|------|------|------|
| 顶部导航 | NavBar | 56rpx | 标题居中，右侧保存草稿 |
| 日志类型 Tab | 自定义 type-tab-bar | — | 三段切换，工作日报选中态高亮 |
| 日期选择 | DatePicker | — | start=昨天 end=今天 |
| 今日工作 | textarea | 2000 字 | 必填，带字数统计 |
| 计划/问题/协调 | textarea | 1000/500/500 | 选填 |
| 提交按钮 | Button | 高 88rpx | 主色，文案「提交工作日报」 |

**交互行为：**
- 切到「工作日报」Tab：清空工作类型与作业人员、隐藏今日状态条；工作类型选择器对该 Tab 隐藏
- 今日工作内容为空时提交 → toast 提示「请输入今日工作内容」
- 提交成功 → toast + navigateBack

**组件复用标注：** NavBar ☑ / Card ☑ / DatePicker ☑ / Toast ☑

## 3. Webapp 端设计

### 3.1 工作日报管理页（report/daily）

**页面路径**：`views/report/daily.vue`

**布局结构（Element Plus 组件）：**

```
┌──────────────────────────────────────────────────────┐
│  AppHeader / AppSidebar（侧栏「工作日报」菜单项）      │
├──────────────────────────────────────────────────────┤
│  筛选区（ElForm inline）                               │
│  [关键词搜索] [状态▾] [开始日期] [结束日期] [刷新]      │
│                                                        │
│  工具栏：共 N 条                                       │
│  ┌────────────────────────────────────────────────┐  │
│  │ ElTable（工作日报列表）                           │  │
│  │ 日报时间│填写人│今日工作│明日计划│问题│协调│状态│操作│  │
│  │ 2026-08-05│张三│…│…│…│…│已通过│ 编辑 删除│  │
│  └────────────────────────────────────────────────┘  │
│  │  ElPagination（分页）                              │
│                                                        │
│  ReportDetailDialog（详情弹窗）/ 编辑弹窗 / 删除确认     │
└──────────────────────────────────────────────────────┘
```

**组件使用说明：**

| 区域 | 组件 | 配置 |
|------|------|------|
| 筛选区 | ElForm inline | 关键词 + 状态 + 日期范围 |
| 数据表格 | ElTable | stripe, border，行点击看详情 |
| 分页 | ElPagination | layout: "total, sizes, prev, pager, next" |
| 详情 | ReportDetailDialog | 复用现有详情弹窗 |
| 编辑 | ElDialog | 四字段 textarea |
| 删除 | ElMessageBox | 确认 + 10 秒可撤销（restoreReport） |

**交互流程：**
1. 进入页面 → `getReportList({ reportType: 'office' })` → 渲染表格
2. 行点击 → `getReportDetail(id)` → 详情弹窗
3. 编辑 → 弹窗预填四字段 → `updateReport` → 刷新
4. 删除 → 确认 → `deleteReport` → 10 秒可撤销
