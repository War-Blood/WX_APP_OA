# 组织架构管理 — 测试样例

> 日期：2026-07-10
> 方法：curl + HTTP 状态码 + 数据库验证

## 前置准备

```bash
TOKEN="$SUPERADMIN_TOKEN"
ADMIN_TOKEN="$ADMIN_TOKEN"
BASE="https://warblood.online/api/admin"
```

## TC-1: admin 查看部门树（权限验证 — GET 不应被拒绝）

```bash
curl -s "$BASE/departments" \
  -H "Authorization: Bearer $ADMIN_TOKEN" | jq '.code'
# 期望: 0 （admin 仍可 GET）
```

## TC-2: admin 尝试新增部门（权限验证 — POST 应被拒绝）

```bash
curl -s -X POST "$BASE/departments" \
  -H "Authorization: Bearer $ADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name":"测试部门","parentId":1}' | jq '{code,message}'
# 期望: code ≠ 0，message 含"权限不足"或"无权限"
```

## TC-3: admin 尝试删除部门（权限验证 — DELETE 应被拒绝）

```bash
curl -s -X DELETE "$BASE/departments/999" \
  -H "Authorization: Bearer $ADMIN_TOKEN" | jq '{code,message}'
# 期望: code ≠ 0
```

## TC-4: superadmin 创建测试部门层级（准备测试数据）

```bash
# 创建根部门
DEPT1=$(curl -s -X POST "$BASE/departments" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name":"测试公司","sortOrder":99}' | jq -r '.data.id')
echo "DEPT1=$DEPT1"

# 创建子部门
DEPT2=$(curl -s -X POST "$BASE/departments" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name":"测试技术部","parentId":'$DEPT1',"sortOrder":99}' | jq -r '.data.id')
echo "DEPT2=$DEPT2"

# 创建孙部门
DEPT3=$(curl -s -X POST "$BASE/departments" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name":"测试前端组","parentId":'$DEPT2',"sortOrder":99}' | jq -r '.data.id')
echo "DEPT3=$DEPT3"
```

## TC-5: 测试数据验证（部门树能查到新部门）

```bash
curl -s "$BASE/departments" \
  -H "Authorization: Bearer $TOKEN" | jq ".data[] | select(.id == $DEPT1) | {name, children: .children | length}"
# 期望: 查到"测试公司"，children 长度 > 0
```

## TC-6: 级联清空删除 — 删根部门（核心测试）

```bash
# 删除 DEPT1（测试公司），应级联删除 DEPT2 和 DEPT3
RESULT=$(curl -s -X DELETE "$BASE/departments/$DEPT1" \
  -H "Authorization: Bearer $TOKEN" | jq '.data')
echo $RESULT
# 期望: data.deletedDeptCount == 3
```

## TC-7: 级联删除后 — 部门树验证

```bash
curl -s "$BASE/departments" \
  -H "Authorization: Bearer $TOKEN" | jq ".data[] | select(.id == $DEPT1)"
# 期望: null （查不到被删的部门）
```

## TC-8: 级联删除后 — 数据库验证（子部门已软删除）

```sql
SELECT id, name, deleted_at FROM departments
WHERE id IN (<DEPT1>, <DEPT2>, <DEPT3>);
-- 期望: 3 行，deleted_at 均不为 NULL
```

## 批量验证脚本（一键跑全部）

```bash
#!/bin/bash
# 保存为 test_org.sh，拷贝 TOKEN 后执行
TOKEN="<superadmin_token>"
ADMIN_TOKEN="<admin_token>"
BASE="https://warblood.online/api/admin"
PASS=0; FAIL=0

assert() {
  if [ "$1" = "$2" ]; then echo "✅ $3"; PASS=$((PASS+1))
  else echo "❌ $3 (got $1, expected $2)"; FAIL=$((FAIL+1)); fi
}

echo "=== TC-1 admin GET ==="
R=$(curl -s "$BASE/departments" -H "Authorization: Bearer $ADMIN_TOKEN" | jq -r '.code')
assert "$R" "0" "admin GET departments"

echo "=== TC-2 admin POST blocked ==="
R=$(curl -s -X POST "$BASE/departments" -H "Authorization: Bearer $ADMIN_TOKEN" \
  -H "Content-Type: application/json" -d '{"name":"x","parentId":1}' | jq -r '.code')
assert "$R" "!=0" "admin POST blocked"

echo "=== TC-3 admin DELETE blocked ==="
R=$(curl -s -X DELETE "$BASE/departments/1" -H "Authorization: Bearer $ADMIN_TOKEN" | jq -r '.code')
assert "$R" "!=0" "admin DELETE blocked"

echo "=== 结果: $PASS 通过, $FAIL 失败 ==="
```
