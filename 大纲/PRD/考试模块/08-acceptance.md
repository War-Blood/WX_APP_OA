# 08 — 验收标准

## 功能验收 Checklist

### 题库管理

- [ ] 管理员可创建题目（单选/多选/判断），选项动态增删
- [ ] 题目可关联分类树节点
- [ ] 题目列表支持按分类/题型/关键词筛选分页
- [ ] 批量导入 100 条，1 条格式错误 → 返回 99 成功 + 1 失败详情
- [ ] 已删除题目不影响已发布试卷（快照机制）

### 试卷管理

- [ ] 管理员可从题库选题组卷，实时显示总分
- [ ] 可设置考试时长、合格分数、最大考试次数、截屏警告上限
- [ ] 可设置参加范围（全员/指定部门）
- [ ] 已发布试卷不可编辑题目内容
- [ ] 修改已发布试卷 → 自动克隆新版，旧版归档

### 考试（小程序）

- [ ] 员工看到 scope 匹配的已发布试卷列表
- [ ] 开始考试 → 生成快照 → 返回 serverTime → 前端倒计时
- [ ] 答题中退出 → 重进自动恢复（doing 记录）
- [ ] 截屏 3 次 → 展示警告 → 超限强制交卷 status='cheated'
- [ ] 交卷 → 基于快照判分 → 返回成绩 + 逐题详情
- [ ] 超时未交卷 → 后端定时任务自动 timeout
- [ ] 同一试卷不可重复开始（已有 submitted/cheated 记录 + max_attempts 限制）

### 练习（小程序）

- [ ] 可选分类/题型/数量 → 开始练习
- [ ] 实时显示对错 + 解析
- [ ] 无时长限制，可随时退出

### 记录与统计（Web）

- [ ] 管理员可按人/按试卷搜索考试记录
- [ ] 选择试卷 → 展示通过率/平均分/分数分布

## 质量门 9 项

| # | 检查项 | 标准 |
|:--:|------|------|
| 1 | 路由冲突 | `/api/exam` 不与现有路由冲突 |
| 2 | 参数化查询 | 所有 SQL 使用 `?` 占位符，禁止拼接 |
| 3 | 权限校验 | 管理端点使用 `requireRole('admin','superadmin')` |
| 4 | 错误处理 | 使用 `BusinessError` + `ErrorCode`，通过 `next(err)` 传递 |
| 5 | 响应格式 | 使用 `success()` / `paginated()` 统一返回 |
| 6 | 提交清理 | 无 `console.log` / `debugger` / 硬编码密钥 |
| 7 | Agent 边界 | 仅修改归属 Agent 管辖目录 |
| 8 | 编码风格 | 后端分号+2空格，小程序无分号+rpx，Web TS+script setup |
| 9 | 日志记录 | 关键操作（考试开始/交卷/作弊）记录 logger |
