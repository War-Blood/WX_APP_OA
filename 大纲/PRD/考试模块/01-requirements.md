# 01 — 产品需求

## 产品愿景

在 OA 系统中为员工提供在线刷题练习和标准化考试能力，支持管理员按部门组织考核，自动判分归档。

## 目标用户与场景

| 用户 | 场景 | 频率 |
|------|------|:--:|
| 员工 | 利用碎片时间模拟练习，自测知识掌握程度 | 日常 |
| 员工 | 参加公司组织的安全/技能/规章正式考试 | 定期 |
| 管理员 | 创建题库、组卷、发布考试、查看全员成绩 | 周期性 |
| 部门负责人 | 查看本部门考试通过率和成绩分布 | 周期性 |

## 功能清单

### P0 — 核心闭环

| # | 功能 | 端 | 说明 |
|:--:|------|:--:|------|
| 1 | 题库管理 | Web | 题目增删改查、分类树、批量导入 |
| 2 | 试卷管理 | Web | 选题组卷、设置时长/分数/合格线/参加部门 |
| 3 | 正式考试 | 小程序 | 限时答题、自动判分、成绩报告 |
| 4 | 模拟练习 | 小程序 | 自由选题型刷题、实时对错反馈 |
| 5 | 考试记录 | 小程序/Web | 我的成绩 / 全员记录查询 |

### P1 — 体验增强

| # | 功能 | 说明 |
|:--:|------|------|
| 6 | 试卷快照 | 考试开始时冻结题目数据，防止管理员改题导致成绩失真 |
| 7 | 防作弊 | 截屏检测+超限强制交卷、计时服务端校验、防重复作答 |
| 8 | 参加范围 | 按部门控制考试参加范围 |
| 9 | 成绩统计 | Web 端通过率/平均分/分数分布图表 |
| 10 | 多选部分分 | 漏选得一半分（管理员可配置） |

### P2 — 锦上添花

| # | 功能 | 说明 |
|:--:|------|------|
| 11 | 断线恢复 | 考试中退出重进自动恢复 |
| 12 | 试卷版本 | 修改已发布试卷时自动克隆+版本号递增 |
| 13 | 批量导入容错 | 部分成功 + 错误回写 |

## 复用机会

| 现有模块 | 复用方式 |
|---------|---------|
| `users` 表 + 部门树 | 考生信息、参加范围校验 |
| `auth` 中间件 (`authenticate`/`requireRole`) | 登录校验 + 管理权限 |
| `toast.js` / `toast.ts` | 双端统一消息提示 |
| `request.js` / `request.ts` | Token 注入 + 错误拦截 |
| `nav-bar` 组件 | 小程序页面导航 |
| `features/index.vue` | 功能中心入口卡片 |
