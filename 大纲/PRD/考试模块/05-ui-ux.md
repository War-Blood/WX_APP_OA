## 一、设计令牌

### 色彩（100% 复用现有框架）

| 变量 | 色值 | 考试模块用途 |
|------|------|------------|
| `$primary` | `#2B6DE8` | 正确标记、主按钮、选中态 |

| `$warning` | `#F59E0B` | 进行中、截屏警告 |

| `$info` | `#909399` | 未参考、草稿状态 |
| `$bg-page` | `#F5F7FA` | 主内容区背景 |
| `$bg-panel` | `#FFFFFF` | 卡片/表格背景 |
| `$bg-hover` | `#F0F2F5` | 表格行 hover、选项 hover |
| `$bg-active` | `#E6F1FB` | 选中选项背景 |
| `$border-light` | `#E4E7ED` | 卡片分隔、表格边框 |
| `$text-primary` | `#303133` | 题干、标题 |
| `$text-regular` | `#606266` | 选项文字、表格内容 |
| `$text-secondary` | `#909399` | 题号、辅助信息 |

### 排版（100% 复用）

| 层级 | 字号/字重 | 考试模块用途 |
|------|----------|------------|
| H1 20px/600 | 页面标题："题库管理""试卷管理" |

| H3 14px/500 | 表格表头 |
| Body 13px/400 | 表格内容、选项文字 |
| Caption 12px/400 | 状态标签、统计数字 |

### 间距（4px 网格）

| 变量 | 值 | 用途 |
|------|-----|------|
| `$space-sm` | 8px | 选项间间距、图标与文字 |
| `$space-base` | 16px | 卡片内边距 |
| `$space-lg` | 20px | 页面内边距 |
| `$space-xl` | 24px | 区块间距 |

## 五、通用交互

| 场景 | 行为 |
|------|------|
| 操作成功 | `toast.success()` 1.5s + 自动刷新列表 |
| 操作失败 | `toast.error(err.message)` 显示后端具体错误 |
| 删除确认 | `ElMessageBox.confirm` type='warning' |
| 表单校验 | 前端必填项校验 + 后端 `ValidationError` |
| 空状态 | 图标 + "暂无数据" + 引导操作按钮 |
| 加载中 | `v-loading="loading"` 表格/卡片骨架 |
