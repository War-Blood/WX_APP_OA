# 05 — UI/UX 设计

## 设计令牌（复用 OA 现有）

| 令牌 | 值 | 用途 |
|------|----|------|
| `--color-primary` | `#2B6DE8` | 主按钮、正确标记 |
| `--color-danger` | `#EF4444` | 错误标记、作弊标签 |
| `--color-warning` | `#F59E0B` | 进行中状态 |
| `--color-success` | `#22C55E` | 通过标记 |
| `--color-bg-page` | `#F0F2F8` | 页面背景 |
| `--color-bg-card` | `#FFFFFF` | 卡片背景 |

## 小程序端

### 考试首页 (`pages/exam/index`)
- 顶部：Tab 切换「模拟练习」「正式考试」
- 模拟练习 Tab：分类卡片网格 + 题型筛选
- 正式考试 Tab：可用考试列表（显示时长/题数/合格线/状态）

### 答题界面 (`pages/exam/practice` / `pages/exam/exam`)
- 顶部：倒计时进度条（仅考试模式）
- 题目区：题号 + 类型标签 + 题干 + 选项列表
- 选项：单选圆形 radio、多选方形 checkbox、判断两个按钮
- 底部：上一题/下一题 + 交卷按钮（考试模式飘红）
- 截屏警告：检测到截屏后弹出 toast「已记录，超过X次将强制交卷」

### 成绩报告 (`pages/exam/result`)
- 总分大字 + 通过/未通过标签
- 逐题详情列表：题号 + 对错图标 + 用户答案 + 正确答案 + 解析

## Web 管理后台

### 题库管理 (`/exam/questions`)
- 左侧：分类树（el-tree）
- 右侧：题目表格 + 分类/题型筛选 + 批量导入按钮
- 弹窗：新增/编辑题目表单（题型select + 选项动态增删 + 解析textarea）

### 试卷管理 (`/exam/papers`)
- 试卷列表 + 新建按钮
- 新建/编辑弹窗：试卷名称/时长/合格线 + 分类筛选 + 题目多选列表 + 参加范围(全员/指定部门树)
- 发布/归档按钮

### 考试记录 (`/exam/records`)
- 筛选栏：按人搜索 + 按试卷筛选
- 表格：考生/试卷/分数/是否合格/用时/状态
- 导出按钮

### 成绩统计 (`/exam/stats`)
- 选择试卷 → 显示通过率饼图 + 平均分 + 分数分布柱状图

## 组件复用

| 页面 | 复用组件 |
|------|---------|
| 小程序所有页面 | `nav-bar`（含 showBack） |
| 小程序答题 | `toast.js` 统一提示 |
| Web 所有页面 | `toast.ts` 统一提示 |
| Web 题库管理 | `el-tree` (部门树复用) |
| Web 试卷管理 | `el-tree-select` 选题 + 选部门 |
| Web 统计 | `dataviz` skill (图表) |
