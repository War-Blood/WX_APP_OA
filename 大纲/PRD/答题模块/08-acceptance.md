# 08 — 验收标准

## 功能验收 Checklist

### 分类管理（Web）

- [ ] 管理员可新增/编辑/删除**单层主分类**（无子分类，v3 扁平化）
- [ ] 分类可设置封面（可选）、建议时长（time）
- [ ] 分类列表显示统计题量 questionNum
- [ ] 删除有子分类或题目的分类 → 拒绝并提示（3002）

### 题库管理（Web）

- [ ] 管理员可创建题目（单选/多选/判断），选项动态增删，可维护正确答案与解析
- [ ] 题目可关联任意主分类；列表支持按分类/题型/关键词筛选分页
- [ ] 批量导入 100 条，1 条格式错误 → 返回 99 成功 + 1 失败详情；错误行号与 Excel 一致，可下载错误明细 CSV
- [ ] 多选判分模式可选 exact / partial

### 练习刷题（小程序）

- [ ] 可选分类/题型/数量/抽题方式（顺序/随机/专项/题型）→ 开始练习
- [ ] 答完显示对错 + 解析
- [ ] 背题模式 → 逐题直接显示答案，供记忆
- [ ] 练习提交后**不产生答题记录**（记录被删除），但答错题归入错题本
- [ ] `use_learn=0` 时练习/背题入口提示"练习模式未开启"

### 模拟考试 / 正式考试（小程序）

- [ ] 选择分类 → 随机抽题 + 倒计时（时长=分类.time）
- [ ] 答题卡网格：已答/未答/当前题状态标色，题号点击跳转
- [ ] 答题变化/离开页面自动保存进度（save-progress），重进断线恢复（剩余时间 + 已答）
- [ ] 交卷 → 基于快照判分 → 返回成绩 + 逐题详情（用户答案/正确答案/解析）
- [ ] 超时未交卷 → 后端定时任务自动置 `timeout`，前端下次进入看到超时结果
- [ ] 同一分类同一模式仅一条进行中记录（防并发重复开始）

### 错题本 / 收藏（小程序）

- [ ] 练习/模拟/考试答错题自动归集到错题本（服务端），支持移除
- [ ] 题目可收藏/取消收藏，收藏列表复习

### 答题记录 / 排行（小程序 + Web）

- [ ] 我的记录（考试/模拟）分页展示，点击进入详情（逐题对错）
- [ ] 排行榜按分类展示 MAX(score) 降序、用时升序，带姓名/部门
- [ ] Web 全员记录按关键词/分类/模式筛选，CSV 导出（带 BOM，Excel 可直接打开）

### 答题设置（Web）

- [ ] `use_learn`（开放练习/背题）、`check_user`（仅登录用户可答）开关保存生效

### 统计看板（Web）

- [ ] 按分类展示答题人数/记录数/平均分/通过率/分类分布

## 质量门 9 项

| # | 检查项 | 标准 |
|:--:|------|------|
| 1 | 路由冲突 | `/api/exam` 不与现有路由冲突 |
| 2 | 参数化查询 | 所有 SQL 使用 `?` 占位符，禁止拼接 |
| 3 | 权限校验 | 管理端点使用 `requireRole('admin','superadmin')` |
| 4 | 错误处理 | 使用 `BusinessError` + `ErrorCode`，通过 `next(err)` 传递 |
| 5 | 响应格式 | 使用 `success()` / `paginated()` 统一返回 |
| 6 | 提交清理 | 无 `console.log` / `debugger` / 硬编码密钥 |
| 7 | Agent 边界 | 仅修改归属 Agent 管辖目录 |
| 8 | 编码风格 | 后端分号+2空格，小程序无分号+rpx，Web TS+script setup |
| 9 | 日志记录 | 关键操作（开始/交卷/超时）记录 logger |

## 测试要点

| 场景 | 预期结果 |
|------|---------|
| 快速双击开始考试 | 唯一索引 → 仅创建一条 doing 记录 |
| 考试中超时 1 秒交卷 | 后端校验 → 置 timeout，按已答判分 |
| 多选漏选（partial 模式） | 得分 = 题分 × (选中正确数/总正确数) |
| 练习提交 | 判分 + 错题归集，练习记录被删除 |
| 背题模式 | 快照返回含 answer，作答不计错题 |
| 断线重进 | 返回 remainingSeconds + savedAnswers，题目快照不变 |
