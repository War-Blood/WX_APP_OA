# 技术调研报告：答题模块三端设计

> 调研日期：2026-08-05
> 调研角色：代码架构师 / 开源情报分析师
> 调研目标：为 OA"答题模块"(原"考试模块",含刷题练习 + 正式考试)寻找可参考的开源三端方案,对比现有实现,支撑 PRD 更新与推进阶段补齐遗留缺口。

---

## 1. 结论摘要

1. 推荐 **学之思(mindskip/xzs)** 作为三端考试系统的 Schema 与功能参考——Web 端 + 微信小程序、Java + Vue 前后端分离、MySQL/PostgreSQL 双版本,社区最成熟。
2. 推荐 **ExamOnline(DavidAlphaFox)** 作为题型与刷题交互参考——8 大题型(单选/多选/填空/判断/阅读等)、多媒体题库、刷题/错题本/收藏/排行榜/激活码/会员体系。
3. 推荐 **kesixin 系列** 作为"三端互通"架构参考——PC/H5/小程序三端数据互通、uniapp 小程序、Java/PHP 后端,覆盖练习(顺序/随机/专项/题型/高频错题)/背题/模拟考试/错题/收藏/排行/签到/积分。
4. **三端分工共识**:小程序 = 答题端(刷题/考试/练习),Web = 管理端(题库/试卷/成绩/统计),后端 = 统一 API。**现有答题模块三端分工与此一致** ✓
5. 现有答题模块三端代码已实现但处于"**暂缓验收**"状态;调研主要用于:确认数据模型合理性、锁定 6 个遗留缺口为 P0、错题本等参考功能列入 P1/P2。

## 4. 数据模型对比

参考项目核心业务链:**题目 — 试卷 — 答题明细 — 成绩/错题**

| 环节 | 参考项目典型表 | 现有 `exam_*` 表 | 对比 |
|---|---|---|---|
| 题库 | `question`(题型/题干/选项/答案/解析/难度/分值) | `exam_questions` ✓ | 一致,含 options JSON |
| 试卷 | `paper` + `paper_question` 关联表(每题分值/排序) | `exam_papers`(question_ids JSON) | 用 JSON 而非关联表(题目量小可接受) |
| 答题 | `exam_answers`(user/paper/question/答案/对错/得分) | `exam_records`(answers JSON + **question_snapshot** 快照) | 用 JSON;快照冻结设计优于参考 |
| 成绩 | `exam_results`(总分/对错数/时长/状态) | `exam_records` ✓ | 一致 |
| 错题 | `e_wrong_question` 或从答题记录 `is_correct=false` 推导 | **无** | 缺口:可从 `exam_records.answers` + 快照推导,成本低 |
| 分类 | `subject`(学科/等级) | `exam_categories`(分类树,表已建) | **无 CRUD** 缺口 |

**结论**:现有 4 表设计与参考项目同构,且快照/版本字段更优;不需要为对齐参考而改表。错题本 P1 可从现有数据推导,不新增表。

## 5. 三端分工共识

| 端 | 职责 | 参考项目对应 |
|---|---|---|
| 小程序 | 答题端:刷题练习 / 正式考试 / 答题记录 / 错题本(待加) | 学之思小程序、ExamOnline |
| Web 后台 | 管理端:题库 / 试卷 / 成绩统计 / 分类管理(待加) | 学之思 Web 管理 |
| 后端 | 统一 API + 定时任务(超时扫描待加) | Java/PHP 服务端 |

现有实现的分工已与此一致,推进阶段主要**补齐缺口**而非重构。

## 6. 对现有模块的建议与差距

### P0(推进阶段实施,已列入 08 验收)
1. 题库分类树管理 — `exam_categories` 表已建,补 API + Web 分类 UI
2. 超时扫描定时任务 — 后端 cron 扫 doing 超时 → timeout
3. 试卷克隆/版本管理 — 修改已发布试卷自动克隆 + version 递增
4. 小程序结果页逐题详情 — 交卷传 details,渲染对错 + 解析
5. 结果页从记录进入传分 — 修复 0 分显示
6. Web `any` 清理 — 补 TS 类型

### P1/P2(参考功能,后续迭代)
- **错题本**(P1,推荐):从 `exam_records.answers` 中 `correct=false` 推导,复习入口
- 背题模式(P2):参考 kesixin 智慧考题宝
- 排行榜/积分(P2):参考 ExamOnline / kesixin(适合趣味竞赛场景)
- 多媒体题库(P2):图片/语音/视频题干(参考 ExamOnline)

### 不建议本期做
- 填空/简答主观题:需关键词/人工判分,复杂度高,与"三种客观题"基调不符
- 试卷-题目关联表重构:现有 JSON 方案在题目量级下够用
