# 答题模块 — 主索引

> **产品一句话概述**：OA 系统答题模块（合并 kesixin/dati 答题端 v2.0 + 企业内部考核试卷制 v2.1）：分类题库管理、练习刷题（顺序/随机/专项/题型 + 背题模式）、模拟考试、正式考试（限时/随机抽题/答题卡/交卷判分）、**试卷制考核（组卷/发放范围/次数/考试窗口，v2.1）**、错题本、收藏、答题记录、排行榜与答题设置，全部在 OA 自有技术栈上实现（Node+MySQL 后端 / uni-app 小程序 / Vue3 Web 后台）。

## v2.1 试卷制说明（2026-08-07，现行）

| 项 | 说明 |
|----|------|
| 需求来源 | `大纲/需求修改/2.md`（用户反馈：正式考试要有次数限制、按部门人员发放、不能人人同一套题） |
| 新增能力 | 后台组卷（手动选题/随机抽题+乱序）、发放范围（全员/部门/人员/角色）、可考次数限制、考试窗口（开始/结束时间）、合格线 pass_score（发起考试时人工设置，**通过判定统一以此为准**） |
| 表/接口 | `exam_papers` 表 + `/api/exam/papers/*`（list/create/update/delete/publish/archive/clone/detail/available）9 路由 |
| 小程序 | 正式考试页改造为「可用试卷列表 → 开始/继续/查看成绩」 |
| Web | 新增试卷管理页 `webapp/src/views/exam/papers.vue` |
| 已砍（2.md P1，无实现，2026-08-07 后废弃） | 一键催考（站内信）、成绩展示控制（result_visibility）、防作弊（切屏/截屏检测）——未实现，从需求中移除 |
| 已移除 | 答题设置 `check_user` 开关（OA 恒有登录用户、无消费端，2026 边界审查后移除） |

## v2.0 合并说明（2026-08-07）

| 项 | 说明 |
|----|------|
| 决策 | 用户调研 [kesixin/dati](https://github.com/kesixin/dati) 后决定：**整个答题系统并入现有 OA 单项目**（非独立小程序、非两个项目），后台管理为 OA Web 单独模块 |
| 技术 | 不用 Bmob 云后端、不用原生微信小程序；按 dati 功能/数据模型在 OA 栈重建（Express+MySQL / uni-app / Vue3） |
| 处置 | **全部删除**旧自研答题模块（`features/exam` 旧实现、exam_papers 试卷模型、防作弊/发放/催考等） |
| 调研结论 | dati 开源仓库为原生小程序（非 uni-app），答题 UI 按 dati 流程在 uni-app 重建，dati 仅作设计参照（详见 `技术调研报告.md`） |
| 范围 | 保留刷题/考试/错题/收藏/排行/记录/设置；丢弃签到/积分/激活码/支付/广告/资讯/独立用户审核 |
