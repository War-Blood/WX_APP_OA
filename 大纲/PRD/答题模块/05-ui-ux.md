# 05 — UI/UX 设计（全状态覆盖）

> 覆盖 Web 端 4 页 + 小程序端 5 页的全部触发状态：常态 / 空态 / 加载态 / 错误态 / 边界态
> 设计依据：OA 前端样式框架（Worktile 风格 v2.0）
> 2026-08-05 更新：新增「浅色纸面感」视觉方向 + 答题卡网格签名（已确认基调）

---

## 零-A、视觉方向（2026-08-05 确认）

> 基调：**浅色纸面感 + 答题卡网格签名 + 等宽数字**（以考试世界的真实器物为语言）

### 纸面感设计令牌

| 令牌 | 色值 | 用途 |
|------|------|------|
| paper | `#F8FAFC` | 纸面底（题目卡片 / 内容区背景） |
| ink | `#1E293B` | 深墨（题干 / 正文，墨色题面） |
| pass | `#16A34A` | 判分绿（答对 / 通过） |
| fail | `#DC2626` | 判错红（答错 / 超时 / 未通过） |
| accent | `#2563EB` | 交互蓝（当前题 / 选中 / 主按钮，承接 OA 主色系） |
| amber | `#D97706` | 警示（倒计时紧迫 / 标记题） |

> 与既有 OA 令牌（`$primary` 等）并存：答题页用本纸面令牌，管理端沿用 OA 令牌。

### 字体策略
- **数字 / 计时 / 分数**：等宽字体（倒计时、答题卡编号、得分对齐）
- **标题 / 正文**：小程序系统默认中文栈；Web 沿用 OA 字体

### ✨ 签名元素：答题卡网格
答题页底部一排方格，每格一题：**已答 = 实心 accent、未答 = 空心 ink、标记 = amber、当前题 = 高亮框**，点击跳题。
答题卡 + 倒计时 + 判分明暗 = 模块辨识度，同时是进度感知与防作弊的载体。

### 管理端（Web）
沿用 OA 标准布局（Element Plus）；成绩统计的分数分布 / 通过率用 ECharts；判分明暗与小程序一致（pass / fail）。

## 小程序页面设计规范

### 按钮置底（强制）

所有小程序页面的操作按钮**必须**使用 `position: fixed; bottom: 0` 置底，**禁止**放在滚动内容区内。

```scss
// 标准置底栏 — 所有小程序页面统一使用
.bottom-bar {
  position: fixed;
  bottom: 0;
  left: 0;
  right: 0;
  padding: 20rpx 24rpx;
  padding-bottom: calc(20rpx + env(safe-area-inset-bottom));
  background: #FFFFFF;
  box-shadow: 0 -2rpx 12rpx rgba(0, 0, 0, 0.04);
  display: flex;
  gap: 16rpx;
  z-index: 100;
}

// 内容区需留出底部空间
.content {
  padding-bottom: calc(140rpx + env(safe-area-inset-bottom));
}
```
