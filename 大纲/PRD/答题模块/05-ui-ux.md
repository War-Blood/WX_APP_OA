# 05 — UI/UX 设计

> v2.0：按 kesixin/dati「智汇答题」答题端交互重建（答题卡网格/背题模式/错题本/排行），沿用「浅色纸面感 + 答题卡网格签名 + 等宽数字」视觉方向（v1 已确认基调）。

## 零、设计令牌（纸面感）

| 令牌 | 色值 | 用途 |
|------|------|------|
| paper | `#F8FAFC` | 纸面底（题目卡片 / 内容区背景） |
| ink | `#1E293B` | 深墨（题干 / 正文） |
| pass | `#16A34A` | 判分绿（答对 / 通过） |
| fail | `#DC2626` | 判错红（答错 / 超时） |
| accent | `#2563EB` | 交互蓝（当前题 / 选中 / 主按钮，承接 OA 主色） |
| amber | `#D97706` | 警示（倒计时紧迫 / 标记题） |

- 数字 / 计时 / 分数使用**等宽字体**；标题正文用系统中文栈。
- **签名元素：答题卡网格** — 底部一排方格，每格一题：已答=实心 accent、未答=空心 ink、当前题=高亮框，点击跳题。
- 管理端（Web）沿用 OA 标准布局（Element Plus）；判分明暗与小程序一致（pass / fail）。

### 小程序按钮置底（强制）

所有小程序页面操作按钮 `position: fixed; bottom: 0` 置底，禁止放入滚动内容区；内容区预留 `padding-bottom: calc(140rpx + env(safe-area-inset-bottom))`。

- 参数 `mode`：learn / mock / exam / rank。
- 主分类宫格列表（无子分类，v3 扁平化）。
- 每卡：封面（可选）、名称、题量 questionNum、建议时长 time。
- 点击 → 对应模式流程；`use_learn=0` 且 mode=learn 时提示"练习模式未开启"。

## 二、Web 答题管理（5 页）

> 复用 PageToolbar / el-table / el-dialog / el-tree 体系。

### 1. 分类管理 `categories.vue`

```
┌─ PageToolbar ─────────────────────────────┐
│  分类管理                          [+ 新增] │
├────────────┬───────────────────────────────┤
│  分类列表   │  选中分类编辑表单：              │
│  低压电工(120)│  名称 [________]            │
│  安全生产(60)│  封面 [上传] (可选)         │
│  规章制度(60)│  建议时长 [10] 分钟          │

│              │  [保存] [删除]                │
└────────────┴───────────────────────────────┘
```
- 删除有题目时禁用并提示（3002）；无子分类概念。

### 2. 题库管理 `questions.vue`

```
┌─ PageToolbar ───────────────────────────────────────────┐
│  题库管理      [分类▼][题型▼][🔍关键词] [+ 新题][批量导入]  │
├──────────────────────────────────────────────────────────┤
│  题型   题干          分类        分值 状态  操作           │
│  [单选] 安全生产三不…  低压电工/基础 2   启用  编辑 删       │
│  [多选] 下列哪些属于…  低压电工/实操 3   启用  编辑 删       │
│  [判断] 高处作业需戴…  低压电工/基础 2   启用  编辑 删       │
└──────────────────────────────────────────────────────────┘
```
- 新增/编辑弹窗：分类树选择、题型（单选/多选/判断）、选项动态编辑器 + 正确项勾选、解析、分值、多选评分模式（全对/部分分）。
- 批量导入弹窗：JSON 上传 → 结果列表（成功数/失败行/错误原因）。

### 3. 成绩记录 `records.vue`

- 筛选：关键词（姓名/工号）+ 分类 + 模式 + 状态。
- 表格：姓名/部门/分类/模式/分数/总分/用时/状态/交卷时间。
- 操作：详情弹窗（逐题对错 + 解析）、导出 CSV（带 BOM）。

### 4. 答题统计 `stats.vue`

- 分类筛选；统计卡：答题人数 / 记录数 / 平均分 / 通过率。
- ECharts：分数分布柱状图 + 分类答题量饼图。

### 5. 答题设置 `settings.vue`

- 开关列表：`use_learn`（开放练习/背题）、`check_user`（仅登录用户可答）。
- el-switch + 保存按钮，保存即生效。

## 三、交互细则

| 场景 | 规则 |
|------|------|
| 多选作答 | 勾选后点「确认」提交本题选择，避免误触 |
| 单选/判断 | 点击即作答（练习态即时判分） |
| 倒计时归零 | 前端自动调交卷；后端超时校验兜底置 timeout |
| 退出考试 | onHide/onUnload 自动 save-progress；弹窗确认"退出后保留进度" |
| 错误答案 | 练习即时标红 + 显示正确答案与解析；考试不即时判分 |
| 空态 | 所有列表页提供友好空态文案 + 引导 |
