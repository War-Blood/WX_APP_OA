# 01 — 产品需求

## 产品愿景

在 OA 系统中为员工提供在线刷题练习、模拟考试与正式考试能力（合并 kesixin/dati 答题端功能面），管理员在 Web 后台统一维护分类题库、查看成绩与排行，自动判分归档。

## 已确认基调（2026-08-07 合并决策后）

| 项 | 结论 |
|------|------|
| 模块名称 | 答题模块（v2.0，合并 kesixin/dati 答题端） |
| 场景定位 | 企业内部考核 / 培训认证 / 刷题学习（分类题库 + 限时考试 + 错题复盘） |
| 题型范围 | 单选 / 多选 / 判断 三种客观题（自动判分，多选支持全对/漏选部分分） |
| 答题端 | OA uni-app 小程序（按 dati 流程重建，dati 仅作设计参照） |
| 管理端 | OA Web 后台独立「答题管理」模块（分类/题库/记录/统计/设置） |
| 身份 | 复用 OA `users` + JWT `req.user.userId`，**不做独立注册审核** |
| 数据 | 落 OA MySQL，**不依赖 Bmob 云后端** |

## 目标用户与场景

| 用户 | 场景 | 频率 |
|------|------|:--:|
| 员工 | 碎片时间刷题练习、背题记忆，自测掌握程度 | 日常 |
| 员工 | 参加公司组织的安全/技能/规章正式考试或模拟考 | 定期 |
| 管理员 | 维护分类题库、批量导入、查看成绩与排行、开关练习/答题设置 | 周期性 |

## 功能清单

### P0 — 核心闭环

| # | 功能 | 端 | 说明 |
|:--:|------|:--:|------|
| 1 | 分类题库管理 | Web | 单层主分类 CRUD（无子分类）+ 题库增删改查 + 批量导入（Excel：分类/题型/题干/选项/答案/解析/分值/判分模式/题干图片） |
| 2 | 练习刷题 | 小程序 | 顺序 / 随机 / 专项（按分类）/ 题型筛选；答完显示对错与解析；支持**背题模式**（直接显示答案） |
| 3 | 模拟考试 | 小程序 | 按分类随机抽题 + 倒计时 + 交卷判分，记录保留 |
| 4 | 正式考试 | 小程序 | 随机抽题 + 答题卡跳转 + 倒计时 + 交卷判分 + 逐题成绩详情 |
| 5 | 错题本 | 小程序 | 练习/考试/模拟答错的题自动归集（服务端），支持移除 |
| 6 | 我的收藏 | 小程序 | 题目收藏/取消收藏，收藏列表复习 |
| 7 | 答题记录 | 小程序/Web | 我的记录（分页）；Web 全员记录 + CSV 导出 |
| 8 | 排行榜 | 小程序 | 按分类按人最高分 + 用时排序（正式/模拟） |
| 9 | 答题设置 | Web | `use_learn`（开放练习/背题）开关（v2.2 起仅此一项；`check_user` 无消费端已移除） |

## 明确丢弃（合并决策 + 后续废弃，不实现）

| 项 | 理由 |
|----|------|
| ~~试卷/考卷模型（exam_papers）~~ | v2.0 曾废弃；**v2.1 已恢复**（企业内部考核试卷制，见 P0-v2.1，2026-08-07） |
| 考卷催考 / 发布通知 | 2.md P1-6 曾列入（站内信催考），**未实现，已砍（2026-08-07 后废弃）** |
| 成绩展示控制（result_visibility） | 2.md P1-7 曾列入（交卷即显示/公布后显示），**未实现，已砍** |
| 防作弊（截屏警告/cheated） | 内部培训场景，成本高收益低（2.md P1-10 曾列入，未实现，已砍） |
| 签到/积分/激活码/虚拟支付/激励广告 | dati 商业化功能，OA 内部场景不需要 |
| 资讯文章 | dati 附带功能，与 OA 定位不符 |
| Bmob 独立用户注册+审核（company/department/realname/status） | 改用 OA 用户体系 |
| 答题设置 `check_user`（仅登录用户可答） | OA 恒有登录用户，开关无消费端，v2.2 移除 |
