# 01 — 产品需求

## 产品愿景

在 OA 系统中为员工提供在线刷题练习和标准化考试（答题）能力，支持管理员按部门组织考核，自动判分归档。

## 已确认基调（2026-08-05 调研后）

| 项 | 结论 |
|------|------|
| 模块名称 | 答题模块（原"考试模块"更名） |
| 场景定位 | 内部考核 / 培训认证（部门参加范围、定时发布、防作弊、合格线、成绩统计） |
| 题型范围 | 单选 / 多选 / 判断 三种客观题（自动判分） |
| 模块范围 | 补齐遗留优先：分类树 / 超时扫描 / 试卷克隆 / 结果页 / 记录传分 / Web 类型 |
| 视觉基调 | 浅色纸面感 + 答题卡网格签名 + 等宽数字（详见 05-ui-ux） |
| 参考基调 | 三端分工对齐学之思 / kesixin：小程序 = 答题端、Web = 管理端、后端 = 统一 API |
| 2026-08-06 参考系统 | 问卷星考试系统（考卷设置：随机抽题/乱序/成绩展示控制；题目设置：分组/选项乱序；发放：通知催考/导出/范围扩展）+ kesixin/dati 答题小程序（答题端 UX：答题卡跳转/背题模式/错题本/排行） |

## 目标用户与场景

| 用户 | 场景 | 频率 |
|------|------|:--:|
| 员工 | 利用碎片时间模拟练习，自测知识掌握程度 | 日常 |
| 员工 | 参加公司组织的安全/技能/规章正式考试 | 定期 |
| 管理员 | 创建题库、组卷、发布考试、查看全员成绩 | 周期性 |
| 部门负责人 | 查看本部门考试通过率和成绩分布 | 周期性 |

## 功能清单

### P0 — 核心闭环

| # | 功能 | 端 | 说明 |
|:--:|------|:--:|------|
| 1 | 题库管理 | Web | 题目增删改查、分类树、批量导入 |
| 2 | 试卷管理 | Web | 选题组卷、设置时长/分数/合格线/参加范围 |
| 2.1 | 随机抽题组卷 | Web | 按题型/分类从题库随机抽 N 题（`draw_rules`），不同考生不同卷（防作弊） |
| 2.2 | 题目+选项乱序 | Web | 试卷级开关，题目顺序 / 每题选项顺序打乱（防背题） |
| 2.3 | 试卷内分组 | Web | 题目归入分组（如"单选部分"），答题端按分组分区展示 |
| 3 | 正式考试 | 小程序 | 限时答题、自动判分、成绩报告 |
| 4 | 模拟练习 | 小程序 | 自由选题型刷题、实时对错反馈 |
| 5 | 考试记录 | 小程序/Web | 我的成绩 / 全员记录查询 |

| `nav-bar` 组件 | 小程序页面导航 |
| `features/index.vue` | 功能中心入口卡片 |
| `messages` 表 + sendMessage 模式 | 发布通知/一键催考站内信（`trip.service.js` 同款） |
