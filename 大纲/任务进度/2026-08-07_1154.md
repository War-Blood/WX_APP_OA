# 答题模块合并 kesixin/dati — 实施计划（2026-08-07）

> 计划归档（R41-43）。已获用户批准。执行全程参考 `大纲/PRD/答题模块/` v2.0 文档。

## 决策

- 形态：**并入 OA 单项目**（非两个项目）；后台管理 = OA Web 单独「答题管理」模块。
- 技术：按 dati 功能/数据模型在 OA 自有栈重建（Express+MySQL / uni-app / Vue3），**不用 Bmob**。
- 处置：**全部删除**旧自研答题模块（含 exam_papers 试卷模型、发放/范围/防作弊/催考）。
- 审计：kesixin/dati 与 QuestionWechatApp 均为原生小程序（非 uni-app），答题 UI 按 dati 流程在 uni-app 重建。
