# PM2 双实例清理备案 — 2026-08-04

## 背景

用户反馈 Web 端"日报管理"显示网络连接失败。排查发现服务器上有**两个 PM2 实例**管理同一个应用 `wx-app-oa-api`,互相竞争端口 3000,导致 ubuntu 实例反复崩溃重启。

## 清理前状态备案(用于回滚)

### root PM2(当前实际提供服务)
- 应用: `wx-app-oa-api` (pm_id 0)
- 用户: root
- 状态: **online**, uptime 15h, restarts 4
- PID: 3594512
- **占用端口 3000**(当前服务由它提供,health 正常)

### ubuntu PM2(重复/幽灵实例,待清理)
- 应用: `wx-app-oa-api` (pm_id 0)
- 用户: ubuntu
- 状态: **waiting restart**(等待重启,无法启动)
- **restart_time: 432989**(重启 43万次,死循环)
- script: `/var/www/wx-app-oa/backend/src/app.js`
- cwd: `/var/www/wx-app-oa/backend`
- env: `NODE_ENV=production`
- **失败原因**: 端口 3000 被 root 进程占用 → EADDRINUSE → 崩溃 → PM2 重启 → 死循环

## 执行操作

```bash
sudo -u ubuntu pm2 delete wx-app-oa-api   # 删除 ubuntu 的重复实例
sudo -u ubuntu pm2 save                    # 保存状态,防止重启后恢复
```

## 回滚方法

若需恢复 ubuntu 的实例:

```bash
# 1. 先停掉 root 实例(释放端口 3000),或用 root 实例让出端口
sudo -u ubuntu pm2 start /var/www/wx-app-oa/backend/src/app.js --name wx-app-oa-api \
  --cwd /var/www/wx-app-oa/backend \
  --env NODE_ENV=production
# 或从 dump 恢复
sudo -u ubuntu pm2 resurrect
```

> ⚠️ 注意:恢复 ubuntu 实例会与 root 实例竞争端口 3000,需先确保只保留一个实例。**推荐:root PM2 为唯一管理实例,不清除 ubuntu 实例的其他 PM2 配置,仅删除该应用。**

## 验证

1. `sudo -u ubuntu pm2 list` 无 wx-app-oa-api
2. `pm2 list`(root)wx-app-oa-api 持续 online
3. 端口 3000 无 EADDRINUSE 新错误
4. 用户刷新日报管理页正常
