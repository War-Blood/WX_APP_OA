## 三、部署步骤

### 方式A：SSH 部署（推荐）
```bash
# 1. 部署后端
scp -r backend/src/* root@111.229.107.123:/var/www/wx-app-oa/backend/src/
ssh root@111.229.107.123 "pm2 restart wx-app-oa-api"

# 2. 验证后端
curl -s http://111.229.107.123:3000/api/health
curl -s -X POST http://111.229.107.123:3000/api/attendance/leave/all-list \
  -H "Authorization: Bearer <TOKEN>" -H "Content-Type: application/json" \
  -d '{"page":1,"pageSize":5}'
# 预期: code=0, 返回 list+total

# 3. 部署 Web 前端
scp -r webapp/dist/* root@111.229.107.123:/var/www/wx-app-oa/webapp/dist/
ssh root@111.229.107.123 "docker exec oa-nginx nginx -s reload"
# 或直接重启 nginx/复制到 nginx 映射目录
```

### 方式B：Git 拉取（如果服务器有 Git）
```bash
ssh root@111.229.107.123 "cd /var/www/wx-app-oa && git pull && pm2 restart wx-app-oa-api"
```

### 小程序部署
1. 微信开发者工具打开 `miniapp/`
2. 编译验证
3. 上传代码 → 提交审核
