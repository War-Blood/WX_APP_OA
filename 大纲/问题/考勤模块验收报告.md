### 数据修复建议
- BUG-01 修复后，需评估数据库中已有的 sick/personal 数据是否需要迁移
- 迁移脚本示例：
  ```sql
  UPDATE attendance_leave_requests SET leave_subtype = 'personal' WHERE leave_subtype = 'sick';
  UPDATE attendance_leave_requests SET leave_subtype = 'sick' WHERE leave_subtype = 'personal';
  ```
  注意：此 SQL 会交换所有 sick 和 personal，仅适用于当前所有受 BUG-01 影响的数据都需要交换的场景
