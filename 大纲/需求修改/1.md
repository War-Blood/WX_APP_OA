# 答题模块需求变更记录

> 更新日期：2026-08-07

## 合并决策（v2.0）

用户决定将开源项目 kesixin/dati 的整套答题系统**并入现有 OA 单项目**（非两个项目），后台管理为 OA Web 单独「答题管理」模块。**旧自研答题模块全部删除**，按 dati 功能/数据模型在 OA 自有栈重建（Express+MySQL / uni-app / Vue3），详见 `大纲/PRD/答题模块/` v2.0 文档。

## 旧需求条目处置

以下为旧自研答题模块（v1.2 考卷/发放方向）的 4 条需求，随模块整体删除而变更：

| 原条目 | 原内容 | v2.0 处置 |
|--------|--------|-----------|
| 1 | 每次模拟都生成记录，给数据库带来负担；每次模拟后直接删除对应记录 | **保留采纳**：合并后练习（learn）提交即删除记录；考试/模拟记录保留 |
| 2 | Web 端发起考试无法选择题目类型，需分类树筛选题目明细 | **废弃**：考卷模型删除，题库管理仍支持按分类树筛选题目（Web 题库管理页保留此能力） |
| 3 | 指定部门没有调用部门树 | **废弃**：考卷发放/部门范围模型删除，不再需要 |
| 4 | 验证各个按钮是否有实际作用 | **废弃**：随旧页面删除；新「答题管理」页面按验收清单（08-acceptance）逐项验收 |
