# 电脑迁移清单

> 将当前开发环境迁移到新电脑需拷贝以下文件和配置

---

## 一、必须拷贝的文件

### 1. SSH 私钥（服务器连接）

```
旧电脑路径 → 新电脑同路径：
C:\Users\WarBlood\.ssh\wx_app_key.pem
C:\Users\WarBlood\.ssh\config
C:\Users\WarBlood\.ssh\known_hosts
```

### 2. 后端环境变量

```
旧电脑路径 → 新电脑同路径：
Y:\AI\WX-APP-OA\backend\.env
```

| 变量 | 用途 |
|------|------|
| `NODE_ENV` | 运行环境 (production/development) |
| `PORT` | 服务端口 |
| `OA_DB_HOST/PORT/USER/PASSWORD/NAME` | 主数据库连接 |
| `OLD_DB_HOST/PORT/USER/PASSWORD/NAME` | 旧版数据库连接 |
| `REDIS_HOST/PORT/PASSWORD/DB` | Redis 缓存连接 |
| `JWT_SECRET` | JWT 签名密钥 |
| `JWT_EXPIRES_IN` | Token 过期时间 |
| `WX_APPID` | 微信小程序 AppID |
| `WX_SECRET` | 微信小程序 Secret |
| `WECHAT_TEMPLATE_ID_REMINDER` | 微信模板消息 ID |
| `QYWX_CORPID/SECRET` | 企业微信（选填） |
| `WPS_API_KEY` | WPS API 密钥（选填） |
| `WECOM_SMARTSHEET_WEBHOOK_KEY` | 企微智能表格 Webhook |
| `LOG_LEVEL/DIR` | 日志配置 |
| `SWAGGER_ENABLED` | API 文档开关 |

## 二、Git 项目

```bash
# 新电脑上执行：
git clone https://github.com/War-Blood/WX_APP_OA.git
cd WX_APP_OA
git checkout test
```

## 三、安装依赖

```bash
cd backend && npm install
cd ../webapp && npm install
cd ../miniapp && npm install
```

## 四、验证

```bash
# 1. SSH 连接测试
ssh -i C:\Users\WarBlood\.ssh\wx_app_key.pem root@111.229.107.123 echo OK

# 2. 后端启动
cd backend && npm run dev

# 3. Webapp 构建
cd webapp && npm run build
```

## 五、不需要迁移的（自动生成）

- `node_modules/` — `npm install` 自动安装
- `dist/` — 构建产物自动生成
- Git 凭据 — 系统凭据管理器自动管理
