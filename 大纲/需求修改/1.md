# 新电脑环境搭建指南

> 从零开始在新电脑上搭建 OA 项目开发环境

---

## 一、安装软件

### 必装

| 软件 | 版本 | 下载 | 备注 |
|------|------|------|------|
| **Node.js** | 18+ LTS | https://nodejs.org | 安装后确认 `node -v` |
| **Git** | 最新 | https://git-scm.com | 安装后配置用户名和邮箱 |
| **微信开发者工具** | 最新稳定版 | https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html | 小程序编译调试 |
| **VS Code**（推荐） | 最新 | https://code.visualstudio.com | 代码编辑 |

### 选装

| 软件 | 用途 |
|------|------|
| **MySQL Workbench** 或 **DBeaver** | 数据库管理 |
| **Redis Insight** | Redis 缓存管理 |
| **Postman** 或 **Apifox** | API 调试 |
| **Git Bash** | Windows 下使用 Linux 命令（Git 自带） |

### 安装后配置 Git

```bash
git config --global user.name "殇血轮回"
git config --global user.email "你的邮箱"
```

---

## 二、拷贝密钥文件

从旧电脑拷贝以下文件到新电脑**同路径**：

| 文件 | 旧电脑路径 | 用途 |
|------|-----------|------|
| `wx_app_key.pem` | `C:\Users\WarBlood\.ssh\` | 服务器 SSH 私钥 |
| `config` | `C:\Users\WarBlood\.ssh\` | SSH 连接配置 |
| `known_hosts` | `C:\Users\WarBlood\.ssh\` | 服务器指纹 |
| `.env` | `Y:\AI\WX-APP-OA\backend\.env` | 后端全部环境变量 |

> ⚠️ 如果新电脑用户名不同，`.ssh` 路径对应调整。SSH 私钥需保持 `600` 权限。


## 六、验证环境

### 1. SSH 连接

```bash
ssh -i C:\Users\WarBlood\.ssh\wx_app_key.pem root@111.229.107.123 echo OK
```

### 2. 后端启动

```bash
cd Y:\AI\WX-APP-OA\backend
npm run dev
# 访问 http://localhost:3000/api/health 返回 {"status":"ok"}
```

### 3. Webapp 构建

```bash
cd Y:\AI\WX-APP-OA\webapp
npm run build
# 输出 dist/ 目录即成功
```

### 4. 小程序编译

```bash
cd Y:\AI\WX-APP-OA\miniapp
npm run build:mp-weixin
# 输出 dist/build/mp-weixin/ → 微信开发者工具导入
```

## 九、常用部署命令

```bash
# 部署后端
scp -i C:\Users\WarBlood\.ssh\wx_app_key.pem backend/src/xxx.js root@111.229.107.123:/var/www/wx-app-oa/backend/src/xxx.js
ssh -i C:\Users\WarBlood\.ssh\wx_app_key.pem root@111.229.107.123 "pm2 restart wx-app-oa-api"

# 部署 Webapp（⚠️ 用 dist/. 不是 dist/）
cd webapp && npm run build
scp -i C:\Users\WarBlood\.ssh\wx_app_key.pem -r dist/. root@111.229.107.123:/var/www/wx-app-oa/admin/

# 部署小程序（微信开发者工具上传）
cd miniapp && npm run build:mp-weixin
```
