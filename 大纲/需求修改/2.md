> 更新日期：2026-08-07
> 说明：现有答题模块（kesixin/dati 合并版，2026-08-07 已部署）功能偏"刷题/自测"，本文件补充**企业内部考核**场景所需的需求清单。

## 一、现状（已具备，2026-08-07 部署）

| 能力 | 端 | 说明 |
|------|-----|------|
| 分类题库 | Web + 小程序 | 单层主分类（无子分类）、单选/多选/判断、批量导入 Excel（含分类/图片列） |

## 二、用户反馈（原始两条，2026-08-07）

> 来自 OA 实际使用反馈，为本需求清单的起点：

1. 答题模式切换到背题模式，再切回题目一直再重新刷新。
2. 正式考试有次数限制，考试试题从后台重新设计。参考一下其他git项目进行修改，现在的考试功能过于宽泛了。不能让所有人靠同一份试题，让指定部门人员考试。

## 三、企业内部考核需求清单

### P0 — 正式考试改造（核心，用户点名）

| # | 需求 | 说明 |
|:--:|------|------|
| 1 | **试卷管理（后台组卷）** | 后台创建试卷：从题库**手动选题**或**按题型/分类随机抽题**组卷；设置时长、合格分、总分、题数、可考次数。试卷绑定分类，取代"选分类即考" |
| 2 | **发放范围** | 全员 / 指定部门 / 指定人员 / 指定角色 四选；范围外人员不可见、不可参加 |
| 3 | **可考次数限制** | 每人每卷 N 次（0=不限）；已达上限禁止再考；**断线恢复不计次** |
| 4 | **考试窗口** | 可设置开始/结束时间（定时开考、到点强制交卷） |
| 5 | **不同考生不同卷** | 随机抽题卷 + 题目/选项乱序，防背题、防雷同（对应反馈第 2 条"不能人人同一套题"） |

### P1 — 考核运营

| # | 需求 | 说明 |
|:--:|------|------|
| 6 | **发布通知 + 一键催考** | 发布试卷给范围内人员发站内信；一键催考提醒未考人员 |
| 7 | **成绩展示控制** | 交卷即显示 / 管理员公布后显示（result_visibility） |
| 8 | **成绩导出 + 统计** | 按试卷/部门导出 CSV/Excel；通过率、平均分、分数段、部门对比 |
| 9 | **补考判定** | 按合格线判定通过/未通过，未通过可重考（配合次数设置） |
| 10 | **防作弊** | 切屏/截屏检测，超限强制交卷（小程序 `onUserCaptureScreen`） |

### P2 — 扩展

| # | 需求 | 说明 |
|:--:|------|------|
| 11 | **主观题（填空/简答）** | 关键词匹配或人工判分（学之思支持；安全案例分析等场景可选） |
| 12 | **答题/背题切换修 bug** | 切换 Tab 保留同一套题（**不重新抽题**），仅切换是否显示答案；背题不计错题（对应反馈第 1 条） |

## 四、实施注记（给开发）

- **P0 1-5**：复用旧 v1.x 已删除的"考卷/发放/范围"设计（git 历史参考 commit `8bb0441`），在现有 dati 模型上扩展：
  - 新增 `exam_papers`（试卷：title/duration/pass_score/total_score/max_attempts/scope_type/scope_departments|users|roles/start_time/end_time/draw_rules/question_ids/status）
  - `exam_records` 增加 `paper_id` 关联试卷（兼容无试卷的练习/背题）
  - 正式考试入口从"选分类即考"改为"选试卷（范围内可见）"；练习/背题/模拟保持按分类
- **P1 6**：复用 `messages` 表（type='exam'）站内信。
- **P1 10**：复用小程序 `onUserCaptureScreen`。
- **P2 12**：小程序 `dati` 页切换 Tab 时不再调用 `learnStart`，复用已加载的同一套题。
- 涉及：DB 迁移（新增试卷表）+ 后端扩展（paper CRUD/发布/范围校验/催考）+ Web 试卷管理页 + 小程序考试入口改造。
