# 题目图片布局规范

> 适用范围：答题模块（题库管理/答题/成绩详情）题目图片的上传约束、推荐尺寸与双端展示布局。
> 版本：v1.0（2026-08-14）

---

## 一、图片类型与字段映射

| 类型 | 字段 | 说明 | 维护入口 |
|------|------|------|----------|
| 题干图 | `exam_questions.title_image` | 题干下方展示的示意图/电路图等 | Web 题目表单上传 / Excel「题干图片」列填 URL |
| 选项图 | `exam_questions.options[].image` | 选项内的图片（如"以下哪个标志"） | Web 题目表单逐选项上传 |
| 解析图 | `exam_questions.analysis_image` | 解析说明配图 | Web 题目表单上传 |
| 分类封面 | `exam_categories.cover` | 小程序分类卡片封面 | Web 分类管理上传 |

> 快照说明：开始答题时题目（含图片字段）冻结进 `question_snapshot`，判分与成绩详情均基于快照，改题不影响进行中答卷。

## 二、推荐尺寸与比例

| 类型 | 推荐比例 | 推荐尺寸 | 说明 |
|------|---------|---------|------|
| 题干图 | 横图 4:3 ~ 16:9 | 宽 800~1600px | 小程序满宽（750rpx）展示，横图观感最佳 |
| 解析图 | 同题干图 | 宽 800~1600px | 同上 |
| 选项图 | 方形或小横图 | ≤400px | 小程序行内限宽 320rpx（约 160px） |
| 分类封面 | 16:9 | 约 750×420px | 小程序分类卡片展示 |

## 三、文件约束（后端强制）

| 项 | 约束 | 实现 |
|----|------|------|
| 格式 | jpg / jpeg / png / webp / gif | `ALLOWED_EXT` 白名单 + sharp 解码校验（防伪造类型） |
| 大小 | ≤ 5MB | multer `fileSize` 限制 |
| 尺寸 | 宽或高 > 1600px 自动等比压缩至 1600 内 | sharp resize（保留原格式；gif 压缩后为静态帧） |
| 文件名 | uuid + 原扩展名 | 防路径穿越与冲突 |
| 访问 | `/uploads/question/<uuid>.<ext>` | `app.js` 静态挂载 + Nginx 反代 |
| 权限 | 仅 admin 可上传 | `POST /api/exam/upload/image`（adminAuth） |

## 四、小程序展示布局（question-card 统一实现）

| 图片 | 布局 | 交互 |
|------|------|------|
| 题干图 | `mode=widthFix` 满宽、圆角 12rpx、max-height 600rpx、灰底 contain | 点击 `uni.previewImage` 全屏预览 |
| 选项图 | 选项行内 `mode=widthFix`、限宽 320rpx、圆角 8rpx | 点击预览（不触发选项选中） |
| 解析图 | 同题干图（解析区底部） | 点击预览 |
| 分类封面 | 分类卡片封面图 | — |

> 所有题目页面（练习/背题/模拟/考试/结果/错题/收藏）均复用 `question-card` 组件，图片布局全局一致。

## 五、Web 展示布局

| 位置 | 布局 |
|------|------|
| 题目表单（新增/编辑） | 题干图/解析图缩略图 48px、选项图 32px，点击 `el-image` 大图预览；上传按钮旁提示"建议横图，宽≤1600px，≤5MB" |
| 成绩记录详情 | 题干图（max-width 320px / max-height 200px contain）、选项图（140px）、解析图（同题干图），均支持点击预览 |
| 分类管理 | 封面上传按钮 + URL 输入 |

## 六、Excel 批量导入图片约定

- 模板「题干图片」列填图片 **URL**（`/uploads/...` 或 `https://...`），可空。
- 选项图暂不支持通过 Excel 维护（选项结构为 JSON，逐题在 Web 表单维护）。
- 模板含三行【示例】数据（单选/多选/判断各一），导入时自动跳过，不会写入题库。

## 七、边界与后续增强（排期外）

- 删除题目不级联删除图片文件（孤儿文件留后续清理任务）。
- 图片防盗链/水印、WebP 统一转码、缩略图版本（`_thumb`）为后续增强项。
