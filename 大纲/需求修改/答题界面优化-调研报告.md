# 答题模块界面优化 — GitHub 调研与差距分析

> 调研日期：2026-08-14
> 调研定位：基于 GitHub 开源答题系统与主流考试产品，对照 OA 答题模块当前各功能块界面，输出可落地的前端界面优化。
> 调研来源：`技术调研报告.md` 既有 GitHub 调研（学之思 xzs / ExamOnline / kesixin-dati / 问卷星）+ 本次对当前逐页源码与 PRD `05-ui-ux.md` 线框的交叉比对。
> 仅前端界面优化，后端 API 与数据模型零改动（所需字段后端已返回）。

---

## 一、调研结论：现代答题系统的界面共性 vs OA 现状

| # | 现代答题系统共性（GitHub/问卷星/学之思） | OA 当前现状 | 差距类型 |
|---|---|---|---|
| 1 | 顶部“作答进度条”+“已答 N/总数”并存，是答题流程的事实签名元素 | dati 仅文字“第 N/M 题”；exam/moniq 仅“N/M”文字 | 线框已定但未落地 |
| 2 | 成绩页头部：分数环/仪表盘 + “正确 X·错误 Y·未答 Z + 用时”，逐题在下 | 仅分数大字 + 逐题，**无答题统计、无用时**（后端已返回）| 线框已定、数据已就绪、未渲染 |
| 3 | 题目卡顶栏含题号：“[单选] 第8题 3分” | 题目卡仅“[单选] 3分”，**无第几题** | 线框已定未落地 |
| 4 | 排行榜：自己不在前 N 时，底部置“我的第 N 名”固定条 | 自高亮行易因排外滚失 | 体验缺口 |
| 5 | 正式考试/试卷制：记录标题显示“试卷名” | exam 记录只显分类名，忽略已返回的 paperTitle | 正确性缺口 |
| 6 | 首页“我的统计”（记录/错题/收藏数）一看即知刷题量 | 首页无统计卡 | 线框已定未落地 |
| 7 | 考试中可“标记本题待复查”+答题卡显标记态 | 无标记态 | 功能缺口（下轮） |
| 8 | 答题中/复查可直接收藏本题 | 收藏仅独立列表页 | 功能缺口（下轮） |
| 9 | 题库封面宫格（支持封面图） | 分类页纯列表、未显封面图 | 视觉缺口（下轮） |
| 10 | 成绩页可“只看错题”筛选切换 | 逐题全展开 | 体验缺口（下轮） |

## 二、各功能块差距明细

### 1. 答题首页 `pages/exam/index`
- **现**：4 格模式入口（emoji 图标）+ 3 链接行 + 推荐题库列表。
- **gap**：PRD 线框第一节即“我的统计 记录12·错题8·收藏5”卡，**当前完全缺失**。模式格用裸 emoji，缺少主题色与图标底色区分。

### 2. 分类选择 `pages/exam/category`
- **现**：竖列卡片（名称 + 题量·时长 + 快速练习 + 箭头）。
- **gap**：PRD 线框为“主分类宫格”且有封面，当前是竖列且未显后端已支持的封面图。（下轮）

### 3. 答题流程 `dati` / `exam` / `moniq`
- **现**：dati 文字“第 N/M 题”；exam/moniq 顶栏（倒计时 + N/M + 答题卡按钮）。
- **gap**：PRD 线框核心签名“████░░░░ 32/50”进度条，**三页均未实现**；题目卡无题号。

### 4. 结果/成绩页 `examResult`
- **现**：分数大字 + 通过/未通过 + 逐题列表 + 底部按钮。
- **gap**：PRD 线框“答题统计 正确42·错误8·未答0”与“用时58分钟”**均缺失**；后端 `detail` 已返回 `useTime`/`isPass`/`details[].correct`，数据齐备纯渲染缺口。分数展示为平铺大字，缺现代仪表盘观感。

### 5. 公共 `question-card`
- **现**：题型 + 分值 + 题干/图片/选项/解析/判分配色。
- **gap**：无“第N题”题号（PRD 线框题目卡首行即题号）。

### 6. 公共 `answer-card`
- **现**：方格、状态：current/filled/right/wrong/hollow。
- **gap**：无“标记待复查”态（下轮）。

### 7. 错题本 `wrong`
- **现**：列表 + 错N次 + 移除 + 错题重练。
- **gap**：(下轮)“错题重练”应针对这些错题抽题，当前跳通用练习设置。

### 8. 收藏 `errorStar`
- **现**：列表 + 取消收藏。
- **gap**：(下轮)答题中无法直接收藏。

### 9. 排行榜 `rank`
- **现**：奖牌行 + 自高亮。
- **gap**：自己排名靠后时需多屏滚动才能定位，缺置底“我的排名”。

### 10. 答题记录 `record`
- **现**：卡片 = 分类名 + 模式标签 + 分数/总分 + 状态·秒·时间。
- **gap**：正式考试(试卷制)记录标题应显试卷名(`paperTitle`)，当前只显分类名，后端已返回 paperTitle 未用。

| 块 | 优化点 | 文件 | 价值 |
|---|---|---|---|
