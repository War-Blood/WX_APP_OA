# 06 — 设计令牌

## 色彩

| 变量 | 色值 | 用途 |
|------|------|------|
| `$primary` | `#2B6DE8` | 主按钮、链接、选中态、正确标记 |
| `$primary-light` | `#E6F1FB` | 选中背景 |
| `$primary-dark` | `#1A5AD4` | active 态 |
| `$success` | `#22C55E` | 成功、通过 |
| `$warning` | `#F59E0B` | 警告、超时 |
| `$danger` | `#EF4444` | 错误、删除、未通过、作弊 |
| `$info` | `#909399` | 次要信息、禁用态 |

| 变量 | 色值 | 用途 |
|------|------|------|
| `$bg-page` | `#F5F7FA` (Web) / `#F7F7F7` (小程序) | 页面背景 |
| `$bg-panel` | `#FFFFFF` | 卡片/表格/侧栏背景 |
| `$bg-hover` | `#F0F2F5` | 列表项 hover |
| `$bg-active` | `#E6F1FB` | 选中项背景 |
| `$border` | `#E4E7ED` | 分隔线/表格边框 |

| 变量 | 色值 | 用途 |
|------|------|------|
| `$text-primary` | `#303133` | 标题/正文 |
| `$text-regular` | `#606266` | 次要正文 |
| `$text-secondary` | `#909399` | 标签/辅助/空态文字 |
| `$text-placeholder` | `#C0C4CC` | placeholder |

## 排版

| 层级 | Web | 小程序 | 用途 |
|------|-----|--------|------|
| H1 | 20px/600 | 36rpx/600 | 页面标题 |
| H2 | 16px/600 | 30rpx/600 | 卡片标题 |
| H3 | 14px/500 | 28rpx/500 | 小标题/表头 |
| Body | 13px/400 | 26rpx/400 | 正文/表格 |
| Caption | 12px/400 | 22rpx/400 | 标签/辅助 |

## 间距（4px 网格）

| 变量 | 值 | 用途 |
|------|-----|------|
| `xs` | 4px (8rpx) | 图标与文字 |
| `sm` | 8px (16rpx) | 紧凑间距 |
| `base` | 16px (32rpx) | 卡片内边距 |
| `lg` | 20px (40rpx) | 页面内边距 |
| `xl` | 24px (48rpx) | 大区块 |

## 小程序专有

| 令牌 | 值 |
|------|-----|
| 圆角-卡片 | 16rpx |
| 圆角-按钮 | 48rpx / 44rpx |
| 按钮高度 | 88rpx / 96rpx（主操作） |
| 最小点击区 | 88rpx × 88rpx |
| 按钮点击态 | `opacity: 0.6`（主按钮）/ 背景 `#F0F2F5`（次按钮） |
| 导航栏 | 自定义 nav-bar（128rpx） |
| 底部标签栏 | 98rpx |
| 安全区 | `env(safe-area-inset-bottom)` |
| 屏幕基准 | 750rpx = 屏幕宽度 |

### 文字颜色 — 行业参考

| 层级 | 色值 | 用途 |
|------|------|------|
| 正文 | `#333333` | 标题、正文 |
| 次要 | `#666666` | 辅助信息 |
| 浅色 | `#999999` | 提示、占位 |

### 字体 — 行业参考

| 层级 | px | rpx | 用途 |
|------|----|-----|------|
| 大标题 | 20px | 40rpx | 页面大标题 |
| 副标题 | 18px | 36rpx | 模块标题 |
| 小标题 | 16px | 32rpx | 卡片标题 |
| 正文 | 14-16px | 28-32rpx | 主要内容 |
| 辅助 | 12px | 24rpx | 次要说明 |
| 最小 | ≥10px | ≥20rpx | 注释/水印 |

> 参考来源：微信官方设计指南 + `rpx = px × 2` 换算（750rpx 基准）
