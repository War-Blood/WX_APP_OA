## 2. API 接入规范

### 2.1 统一响应格式

所有 API 响应遵循统一的 JSON 结构：

```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `code` | number | 业务状态码（0=成功，非0=失败） |
| `message` | string | 状态描述信息 |
| `data` | object/array/null | 业务数据载体 |

### 2.2 成功响应示例

**简单返回：**
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "userId": "U10001",
    "nickName": "张三",
    "role": "employee"
  }
}
```

**列表返回：**
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "total": 42,
    "list": [
      { "id": "1", "name": "项目A" },
      { "id": "2", "name": "项目B" }
    ]
  }
}
```

**空数据返回：**
```json
{
  "code": 0,
  "message": "success",
  "data": null
}
```

### 2.3 失败响应示例

```json
{
  "code": 1001,
  "message": "参数校验失败: code 为必填字段",
  "data": null
}
```

### 2.4 HTTP 方法使用规范

| 方法 | 用途 | 说明 |
|------|------|------|
| `GET` | 查询资源 | 获取列表、详情（如 `/api/user/profile`） |
| `POST` | 创建资源 / 复杂查询 | 创建审批、日报提交、带筛选条件的列表查询 **（注：本项目列表接口统一使用 POST 以支持复杂查询参数）** |
| `PUT` | 更新资源 | 更新用户资料等 |
| `DELETE` | 删除资源 | 删除草稿日报等 |

> **注意：** 本项目中列表查询接口（如 `/api/approval/list`、`/api/report/list`）统一使用 **POST** 方法，因为查询参数复杂（多条件筛选、分页、排序等），使用 POST 更便于传递结构化参数。

### 2.5 请求参数传递规范

| 参数位置 | 适用场景 | 示例 |
|----------|----------|------|
| `URL Path` | 资源标识 | `/api/approval/detail?id=xxx` |
| `Request Body (JSON)` | POST/PUT 参数 | `{"page":1,"pageSize":20}` |
| `Query String` | GET 请求参数 | `?keyword=张三&page=1` |
| `Header` | 认证、元数据 | `Authorization: Bearer <token>` |

## 3. 错误码处理规范

### 3.1 完整错误码表

| code | HTTP Status | 含义 | 前端处理方式 |
|------|-------------|------|-------------|
| **0** | 200 | ✅ 成功 | 正常处理返回数据 |
| **401** | 401 | ❌ 未授权 / Token 过期 | 清除本地 Token，跳转登录页 |
| **403** | 403 | ❌ 无权限 | Toast 提示"无权限访问" |
| **1001** | 400 | ❌ 参数校验失败 | Toast 显示 `message` 中的具体错误 |
| **1002** | 404 | ❌ 资源不存在 | Toast 提示"资源不存在" |
| **2001** | 200 | ❌ 业务逻辑错误 | Toast 显示 `message` 中的具体错误 |
| **2002** | 200 | ❌ 审批已处理 | 刷新列表（静默处理） |
| **2003** | 200 | ❌ 日报已审核 | 刷新详情（静默处理） |
| **500** | 500 | ❌ 服务器内部错误 | 统一提示"服务器繁忙，请稍后重试" |

### 3.2 前端错误码处理逻辑

```javascript
/**
 * 统一错误码处理
 * @param {Object} response - 后端响应对象 { code, message, data }
 * @returns {Boolean} - true=成功, false=失败
 */
function handleResponse(response) {
  if (response.code === 0) {
    // 成功：正常处理
    return response.data;
  }

  // 根据 code 分类处理
  switch (response.code) {
    case 401:
      // 清除本地存储的 token
      uni.removeStorageSync('token');
      // 跳转登录页
      uni.reLaunch({ url: '/pages/login/login' });
      break;

    case 403:
      uni.showToast({ title: '无权限访问', icon: 'none' });
      break;

    case 1001:
      // 参数校验失败，显示具体错误信息
      uni.showToast({ title: response.message, icon: 'none' });
      break;

    case 1002:
      uni.showToast({ title: '资源不存在', icon: 'none' });
      break;

    case 2001:
      // 业务逻辑错误，显示具体错误信息
      uni.showToast({ title: response.message, icon: 'none' });
      break;

    case 2002:
    case 2003:
      // 业务冲突（已处理），静默刷新
      console.warn(response.message);
      break;

    default:
      // 未知错误
      uni.showToast({ title: '服务器繁忙，请稍后重试', icon: 'none' });
  }

  return false;
}
```

### 3.3 网络层错误处理

除了业务错误码，还需要处理网络层面的异常：

| 场景 | HTTP 状态 | 前端处理 |
|------|-----------|----------|
| 网络不可用 | - | 提示"网络连接异常，请检查网络设置" |
| 请求超时 | - | 提示"请求超时，请稍后重试" |
| 服务器错误 | 500 | 提示"服务器繁忙，请稍后重试" |
| 服务不可用 | 502/503 | 提示"服务暂不可用，请稍后重试" |
| 限流 | 429 | 提示"请求过于频繁，请稍后再试" |

## 4. 认证头传递规范

### 4.1 认证方式

采用 **JWT Bearer Token** 认证：

```
Authorization: Bearer <token>
```

### 4.2 获取 Token

**登录成功后从响应中获取：**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIs...",
    "userInfo": { ... }
  }
}
```

### 4.3 Token 存储

| 平台 | 存储方式 | 示例 |
|------|----------|------|
| 微信小程序 | `uni.setStorageSync('token', token)` | 本地缓存 |
| Web 管理后台 | `localStorage.setItem('token', token)` | 浏览器本地存储 |

### 4.4 Token 传递规则

**所有需要认证的接口（除 `/api/auth/*`、`/api/health` 外）都必须携带 Authorization 头：**

```javascript
// uni-app 请求拦截器示例
uni.addInterceptor('request', {
  invoke(args) {
    const token = uni.getStorageSync('token');
    if (token) {
      args.header = {
        ...args.header,
        'Authorization': `Bearer ${token}`
      };
    }
    return args;
  }
});
```

### 4.5 Token 过期处理

Token 过期时，后端返回 `code: 401`，前端应：

1. 清除本地存储的 Token
2. 跳转至登录页面
3. （可选）记录当前页面路径，登录成功后跳回

> **注意：** Token 有效期默认 7 天。临近过期时，后端暂不提供自动刷新机制，用户需重新登录。如未来业务需要，可扩展 Refresh Token 机制（M3 阶段确认）。

### 4.6 免认证接口清单

以下接口不需要携带 Authorization 头：

| 接口 | 说明 |
|------|------|
| `POST /api/auth/login` | 微信登录 |
| `GET /api/health` | 健康检查 |
| `GET /api-docs` | Swagger API 文档页面 |
| `POST /api/auth/admin/login` | Web 管理后台登录（M3 实现） |

## 5. 分页请求与响应规范

### 5.1 分页请求格式

所有列表接口使用统一的分页请求参数：

```json
{
  "page": 1,
  "pageSize": 20,
  // ... 其他筛选条件
}
```

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `page` | number | 否 | 1 | 页码，从 1 开始 |
| `pageSize` | number | 否 | 20 | 每页条数（最大 100） |

### 5.2 分页响应格式

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "total": 100,
    "list": []
  }
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `total` | number | 总记录数 |
| `list` | array | 当前页数据列表 |

### 5.3 前端分页实现建议

```javascript
// 分页数据管理示例
const PAGE_SIZE = 20;

export function usePagination(fetchFn) {
  const list = ref([]);
  const total = ref(0);
  const page = ref(1);
  const loading = ref(false);
  const hasMore = computed(() => list.value.length < total.value);

  async function loadMore() {
    if (loading.value || !hasMore.value) return;
    loading.value = true;
    try {
      const res = await fetchFn({ page: page.value, pageSize: PAGE_SIZE });
      list.value = [...list.value, ...res.list];
      total.value = res.total;
      page.value++;
    } finally {
      loading.value = false;
    }
  }

  async function refresh() {
    page.value = 1;
    list.value = [];
    total.value = 0;
    await loadMore();
  }

  return { list, total, loading, hasMore, loadMore, refresh };
}
```

## 6. 前端请求封装推荐实现

### 6.1 微信小程序（uni-app）

```javascript
// src/services/request.js — 统一请求封装
const BASE_URL = 'https://warblood.online';

function request(config) {
  return new Promise((resolve, reject) => {
    const token = uni.getStorageSync('token');

    uni.request({
      url: `${BASE_URL}${config.url}`,
      method: config.method || 'POST',
      data: config.data || {},
      header: {
        'Content-Type': 'application/json',
        ...(token ? { 'Authorization': `Bearer ${token}` } : {}),
        ...config.header,
      },
      success(res) {
        const { code, message, data } = res.data;

        if (code === 0) {
          resolve(data);
        } else {
          // 统一错误处理
          handleError(code, message);
          reject({ code, message });
        }
      },
      fail(err) {
        uni.showToast({ title: '网络异常，请稍后重试', icon: 'none' });
        reject(err);
      },
    });
  });
}

function handleError(code, message) {
  switch (code) {
    case 401:
      uni.removeStorageSync('token');
      uni.reLaunch({ url: '/pages/login/login' });
      break;
    case 403:
      uni.showToast({ title: '无权限访问', icon: 'none' });
      break;
    default:
      uni.showToast({ title: message || '请求失败', icon: 'none' });
  }
}

export default {
  get(url, params) {
    return request({ url, method: 'GET', data: params });
  },
  post(url, data) {
    return request({ url, method: 'POST', data });
  },
  put(url, data) {
    return request({ url, method: 'PUT', data });
  },
  delete(url, data) {
    return request({ url, method: 'DELETE', data });
  },
};
```

### 6.2 Web 管理后台（Axios）

```javascript
// src/utils/request.js — Axios 封装
import axios from 'axios';

const service = axios.create({
  baseURL: 'https://warblood.online',
  timeout: 15000,
  headers: { 'Content-Type': 'application/json' },
});

// 请求拦截器 — 自动添加 Token
service.interceptors.request.use(
  (config) => {
    const token = localStorage.getItem('token');
    if (token) {
      config.headers.Authorization = `Bearer ${token}`;
    }
    return config;
  },
  (error) => Promise.reject(error)
);

// 响应拦截器 — 统一错误处理
service.interceptors.response.use(
  (response) => {
    const { code, message, data } = response.data;

    if (code === 0) {
      return data;
    }

    switch (code) {
      case 401:
        localStorage.removeItem('token');
        window.location.href = '/login';
        break;
      case 403:
        ElMessage.warning('无权限访问');
        break;
      default:
        ElMessage.error(message);
    }

    return Promise.reject({ code, message });
  },
  (error) => {
    if (error.code === 'ECONNABORTED') {
      ElMessage.error('请求超时，请稍后重试');
    } else {
      ElMessage.error('网络异常，请检查网络连接');
    }
    return Promise.reject(error);
  }
);

export default service;
```

## 7. 接口调用注意事项

### 7.1 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 接口返回 401 | Token 缺失或过期 | 重新登录获取新 Token |
| 接口返回 403 | 当前用户角色无权限 | 联系管理员开通权限 |
| 接口返回 1001 | 请求参数格式错误 | 检查必填字段和参数类型 |
| 接口返回 500 | 服务器异常 | 查看后端日志定位问题 |
| CORS 错误 | 跨域配置问题 | 后端需配置正确的 CORS 白名单 |

### 7.2 微信小程序特殊说明

微信小程序中，**不支持 Cookie**，所有认证必须通过 `Authorization` 头传递 Token。此外：

1. 请求的域名需在小程序管理后台配置白名单（`warblood.online` 或开发 IP）
2. 小程序中不支持 `eval` 或 `new Function`，API 返回的数据不可作为可执行代码
3. 上传文件使用 `uni.uploadFile`，Token 通过 `formData` 或 `header` 传入

### 7.3 请求超时设置

| 接口类型 | 建议超时时间 | 说明 |
|----------|-------------|------|
| 常规查询接口 | 10s | 用户列表、审批列表等 |
| 提交/更新接口 | 15s | 提交日报、发起审批等 |
| 文件上传接口 | 60s | 头像上传、附件上传等 |

### 7.4 数据格式约定

| 数据类型 | 格式 | 示例 |
|----------|------|------|
| 日期 | `YYYY-MM-DD` | `2026-05-27` |
| 日期时间 | `YYYY-MM-DD HH:mm:ss` | `2026-05-27 14:30:00` |
| 金额 | 字符串（保留两位小数） | `"1500.00"` |
| 百分比 | 字符串 | `"67%"` |
| 图片 URL | 完整 URL | `https://warblood.online/uploads/avatar.jpg` |
| 状态枚举 | 小写英文字符串 | `pending`、`approved`、`rejected` |
