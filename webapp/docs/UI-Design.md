## 1. 页面层级结构（L1-L4）

### 1.1 层级定义

| 层级 | 定义 | 交互形式 | 示例 |
|------|------|---------|------|
| **L1** | 一级导航菜单（侧边栏主菜单项） | 页面级跳转 | 仪表盘、用户管理 |
| **L2** | 二级页面（子菜单项或Tab页） | 页面级跳转 | 用户列表、部门管理 |
| **L3** | 三级详情/配置页（从L2深入） | 页面级跳转（带返回） | 用户详情、审批模板配置 |
| **L4** | 弹窗/抽屉级（叠层交互） | 弹窗/抽屉/气泡卡片 | 创建用户弹窗、角色分配抽屉 |

### 1.3 页面层级统计

| 层级 | 数量 | 说明 |
|------|------|------|
| L1 | 13 | 12个模块 + 登录页（独立） |
| L2 | 28 | 二级子页面 |
| L3 | 10 | 三级详情/配置页面 |
| L4 | 58 | 弹窗/抽屉等叠层交互 |
| 合计 | 109 | 全量交互单元 |

### 1.4 页面层级路由设计原则

```
路由命名规范：
/module/[sub-page]/[detail]/[action]

示例：
/approval/template/:id/config    # 审批模板配置页（L3）
/user/list                       # 用户列表（L2）
/user/:id                        # 用户详情（L3）

路由层级与页面层级的对应：
L1  → /module                     # 一级路由，默认重定向到该模块的L2首页
L2  → /module/sub-page            # 二级路由，具体子页面
L3  → /module/sub-page/:id/...    # 三级路由，带参数
L4  → 不占用路由，由组件内部状态控制（弹窗/抽屉）
```

#### 2.2.3 弹窗/抽屉通用交互规范

```
┌──────────────────────────────────────────────────────┐
│  弹窗/抽屉头部                                        │
│  [图标/标题]                              [关闭按钮 X] │
├──────────────────────────────────────────────────────┤
│                                                      │
│  弹窗/抽屉内容区域                                     │
│  (表单/详情/配置)                                     │
│                                                      │
│                                                      │
├──────────────────────────────────────────────────────┤
│  弹窗/抽屉底部操作栏                                   │
│  [次要操作]                          [取消] [确认(主要)]│
└──────────────────────────────────────────────────────┘
```

**交互规则**:

1. **关闭方式**: 点击右上角X、点击遮罩层（弹窗可点击遮罩关闭，抽屉可点击遮罩关闭）、按ESC键
2. **表单弹窗**: 点击确认时先做表单校验，校验失败时定位到第一个错误字段并高亮
3. **确认对话框**: 主要操作为危险操作时按钮使用 Danger 色（红色），普通操作用 Primary 色
4. **数据变更提示**: 表单有未保存内容时点击取消/X，弹出"是否放弃修改"提示
5. **加载状态**: 提交时按钮显示 loading 状态，禁止重复提交
6. **抽屉关闭**: 抽屉关闭时支持过渡动画（300ms ease-out）
