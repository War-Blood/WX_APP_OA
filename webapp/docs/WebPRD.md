## 1. 文档概述

### 1.1 文档目的

本文档旨在定义 **OA管理后台（Web端）** 的产品需求，作为后续设计、开发、测试和验收的统一依据。本后台的核心使命是：**让运维人员能够高效管理小程序端的所有内容、用户、权限和系统配置**，实现"一个后台管全部"的运维目标。

## 2. 产品定位

### 2.1 项目背景

本项目是 **WX-APP-OA 系统** 的 Web 后台管理端。目前系统已上线微信小程序端，覆盖工作台、审批、日报、任务项目、资产管理、消息公告、个人中心等七大核心功能模块。

随着小程序端用户量和业务数据的增长，运维人员面临以下挑战：
- **管理分散**：用户管理、权限配置、审批模板配置散落在不同地方
- **内容不可控**：小程序工作台上的快捷入口、功能模块无法灵活编排
- **数据不可见**：没有全局数据看板，无法了解系统整体运营状态
- **运维缺乏工具**：操作日志、运行监控、数据备份等运维功能缺失

因此，亟需一个 **面向运维人员** 的 Web 管理后台，提供小程序内容管理、用户权限管控和系统运维监控的一站式解决方案。

### 2.2 产品定位

| 维度 | 说明 |
|------|------|
| **产品名称** | OA管理后台 |
| **产品形态** | Web端管理后台（B/S架构） |
| **核心目标用户** | 运维人员（系统管理员） |
| **核心价值** | 一站式管理小程序全部内容，精细化控制用户权限，全方位运维监控 |
| **与小程序的关系** | 小程序是"前台"面向员工，后台是"中控台"面向管理员，共享同一套后端服务和数据 |

## 3. 目标用户分析

### 3.1 用户角色定义

| 角色 | 角色ID | 描述 | 核心诉求 |
|------|--------|------|----------|
| **运维人员** | `system_admin` | 企业IT管理员，负责系统日常运维、用户管理和安全管控 | 小程序内容编排、用户权限管理、系统配置、运行监控、操作审计 |
| **业务管理员** | `biz_admin` | 部门主管/项目经理，关注业务数据和团队管理 | 日报审核、项目跟踪、审批监控、部门数据查看 |

#### 4.1.4 交互说明

- **核心指标卡**：鼠标悬停显示详细数值和环比变化趋势
- **趋势图表**：支持Tab切换查看不同指标，点击图例可筛选
- **时间范围筛选**：提供「今日」「本周」「本月」「自定义」四个快捷选项，切换时所有图表联动刷新
- **待处理事项**：每项右侧提供「处理」按钮，点击跳转到对应处理页面；已处理事项自动从列表消失
- **快捷操作**：点击图标直接跳转到对应功能模块

### 4.2 小程序内容编排

#### 4.2.1 功能概述

**小程序内容编排是后台最核心的能力之一**，让运维人员可以灵活配置小程序端的展示内容和功能。通过可视化界面，运维人员可以编排工作台快捷入口、控制功能模块的启用/禁用、配置小程序首页展示内容等，无需修改代码即可灵活调整小程序的前端表现。

| LYT-04 | 首页轮播公告配置 | 配置小程序首页顶部轮播的公告内容 | P1 |
| LYT-05 | 数据概览卡片配置 | 配置小程序工作台数据概览区域展示哪些指标 | P1 |
| LYT-06 | 审批类型可见性配置 | 控制小程序中显示哪些审批类型 | P0 |

### 4.5 审批管理

#### 4.5.1 功能概述

审批管理对应小程序端「审批流程模块」的全部后台管理能力。分为**审批模板管理**（定义审批流程的"模板"层）和**审批实例管理**（管理已发起的审批"实例"层）。运维人员可以通过可视化界面配置审批表单和流程，也可对运行中的审批进行监控和干预。

- 控制审批类型在小程序端的可见性

- **审批人设置**：支持指定用户/指定角色/上级主管/发起人自选四种模式
- **实例干预**：管理员可代为审批（通过/驳回）、转交（转给其他人）、撤回（回发起人）、终止（强制结束）

### 6.3 业务规则

| 规则ID | 规则描述 | 所属模块 |

| RULE-03 | 删除部门需确保部门下无成员 | 用户管理 |
| RULE-04 | 角色权限修改后已分配用户即时生效 | 角色权限 |

| RULE-06 | 工作台配置修改后即时同步到小程序端（下次进入生效） | 内容编排 |
| RULE-07 | 审批超时阈值以节点配置为准 | 审批管理 |
| RULE-08 | 日报提交截止时间以系统配置为准 | 日报管理 |
| RULE-09 | 公告已发布后编辑需生成新版本，保留编辑历史 | 公告管理 |
| RULE-10 | 操作日志不可删除，保留期默认180天 | 系统设置 |
