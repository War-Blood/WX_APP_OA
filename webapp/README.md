# Web端管理后台

## 项目简介

本项目是 **WX-APP-OA** 系统的 Web 端管理后台，定位为 **小程序内容中控台 + 系统运维平台**，基于 Vue 3 + TypeScript + Vite 技术栈开发，为运维人员（系统管理员）提供基于浏览器的一站式管理界面。

## 所属系统

本项目是 WX-APP-OA 系统的子项目之一：

| 子项目 | 技术栈 | 说明 |
|--------|--------|------|
| `miniapp/` | uni-app (Vue 3) → 微信小程序 | 员工端小程序 |
| `webapp/` | Vue 3 + TypeScript + Vite | **管理后台（本项目）** |
| `backend/` | Node.js + Express | 服务端后端 |
| `test/` | Node.js | 测试工具 |

## 功能模块

- **仪表盘** - 全局数据看板、待办事项、系统状态
- **小程序内容编排** - 工作台配置、功能模块开关、角色菜单可见性
- **用户管理** - 用户CRUD、部门管理、批量导入导出
- **角色权限管理** - 自定义角色、权限矩阵配置、角色分配
- **审批管理** - 审批模板/流程配置、实例监控、超时管控
- **日报管理** - 提交率统计、批量审核、导出、模板配置
- **任务与项目管理** - 项目总览、任务看板、进度统计
- **资产管理** - 资产台账、领用审批、盘点、报表
- **公告管理** - 发布、阅读统计、范围控制
- **消息管理** - 消息模板、手动推送
- **系统设置** - 企业信息、安全策略、操作日志、运行监控、数据备份

## 技术栈

- **前端框架**: Vue 3 + TypeScript
- **构建工具**: Vite
- **UI组件库**: Element Plus
- **状态管理**: Pinia
- **路由**: Vue Router
- **HTTP客户端**: Axios
- **后端接口**: 对接现有云函数/Node.js后端

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 代码检查
npm run lint

# 类型检查
npm run type-check
```
