## 1. 设计概述

### 1.1 设计目标

- **一致性**：建立统一的设计语言，确保所有页面视觉风格和交互行为一致
- **效率优先**：以「高效办公」为核心设计理念，减少操作步骤，优化任务流程
- **角色适配**：员工端与管理端差异化设计，管理员视图突出数据与审核，员工视图突出执行与提交
- **移动优先**：基于微信小程序移动端特性，单手操作可达，关键按钮位于屏幕下半区

### 1.2 设计原则

| 原则 | 说明 |
|------|------|
| **清晰** | 每个页面只有一个核心任务，信息层级分明，用户一眼可知当前页面用途 |
| **轻量** | 减少不必要的视觉装饰，卡片式布局降低认知负荷，内容为王 |
| **高效** | 高频操作（提交日报、审批）固定底部按钮，减少手指移动距离 |
| **反馈** | 每次操作都有即时反馈（加载态、成功/失败提示），消除等待焦虑 |
| **容错** | 关键操作二次确认，表单自动保存草稿，错误可恢复 |

### 1.3 页面层级定义

| 层级 | 定义 | 数量 | 示例 |
|------|------|------|------|
| **L1** | 主Tab页，底部导航栏直接访问 | 3 | 首页、功能中心、个人中心 |
| **L2** | 功能模块首页/列表页，从L1或功能入口跳转 | 12 | 审批中心、日报历史、任务看板 |
| **L3** | 详情/编辑页，从L2列表项跳转 | 10 | 日报详情、审批详情、日报编辑 |
| **L4** | 操作弹窗/浮层，临时性交互 | 8 | 确认弹窗、人员选择器、图片预览 |

### 2.2 L1 — 一级页面（主Tab页）

底部导航栏三个主Tab，覆盖用户核心操作路径。

#### [L1-01] 首页（工作台）

| 设计要素 | 说明 |
|---------|------|
| **页面用途** | 用户登录后默认首页，聚合待办、快捷入口、数据概览 |
| **布局结构** | 顶部用户信息 → 待办面板 → 快捷入口 → 数据概览 → 最近动态 → 公告轮播 |
| **滚动性** | 整页可纵向滚动 |
| **刷新机制** | 下拉刷新（重新拉取待办和数据概览） |
| **空状态** | 待办为0时显示「暂无待办事项」，引导用户探索其他功能 |
| **角色差异** | 管理员：显示待审核日报数、待处理审批数；员工：显示日报提交提醒、审批结果 |

#### [L1-02] 功能中心

| 设计要素 | 说明 |
|---------|------|
| **页面用途** | 所有功能模块的集合入口，网格布局 |
| **布局结构** | 顶部搜索/标题 → 2×4 或 3×3 功能图标网格 |
| **功能入口** | 审批中心、日报管理、任务管理、项目管理、资产管理、公告中心、消息中心 |
| **角色差异** | 管理员额外显示「审核管理」「用户管理」入口 |
| **交互** | 长按图标可自定义排列（可选功能） |

#### [L1-03] 个人中心

| 设计要素 | 说明 |
|---------|------|
| **页面用途** | 展示个人信息、数据统计、设置入口 |
| **布局结构** | 顶部用户头像/信息卡片 → 数据统计区 → 功能列表 → 设置区 |
| **数据统计** | 本月日报数、审批数、任务完成数 |
| **功能列表** | 我的日报、我的审批、我的任务 |
| **管理入口** | 用户管理、审核管理（仅管理员可见） |
| **设置区** | 通知设置、关于我们、退出登录 |

### 2.5 L4 — 四级页面（操作弹窗/浮层）

#### [L4-01] 确认弹窗（Confirm Dialog）

| 设计要素 | 说明 |
|---------|------|
| **触发场景** | 删除、驳回、退出登录、禁用用户等不可逆操作 |
| **构成** | 遮罩层 + 居中卡片：图标 + 标题 + 描述 + 取消/确认按钮 |
| **按钮** | 取消（次要）+ 确认（主色/危险色）|
| **关闭方式** | 点击遮罩层关闭 / 点击取消关闭 |

#### [L4-02] Toast 轻提示

| 设计要素 | 说明 |
|---------|------|
| **触发场景** | 操作成功/失败反馈 |
| **构成** | 居中半透明黑底圆角卡片 + 图标 + 文字 |
| **持续时间** | 成功1.5s，失败2s，可手动关闭 |
| **位置** | 屏幕居中偏上 |

## 4. 高效蓝主题配色方案

### 4.1 色彩设计理念

**"高效蓝"** 以专业、信任、冷静为核心关键词，蓝色系在办公软件中广泛使用，传达：
- **专业感**：蓝色是商业领域最受信赖的色彩，适合企业办公场景
- **高效率**：蓝色具有冷静、理性的视觉暗示，有助于专注工作
- **普适性**：蓝色对性别、年龄的包容性最强，适合全员使用
- **层次分明**：蓝色系从深到浅的跨度大，便于构建信息层级

| 错误场景 | 用户提示 | 引导操作 |
|---------|---------|---------|
| 网络错误 | 「网络连接异常，请检查网络后重试」 | 显示「重试」按钮 |
| 请求超时 | 「请求超时，请稍后重试」 | 自动重试1次 + 「重试」按钮 |
| Token过期 | 自动跳转登录页 | 静默重新登录 |
| 无权限 | 「您没有权限执行此操作」 | 「返回首页」按钮 |
| 表单校验失败 | 高亮错误字段 + 显示错误提示 | 自动聚焦第一个错误字段 |
| 提交失败 | 「提交失败，请稍后重试」 | 保留已填写内容 + 「重试」按钮 |
| 空数据 | 展示空状态组件 | 引导创建/返回 |
