## 1. 设计尺寸与适配基准

### 1.1 设计稿基准

| 项目                 | 标准       | 说明                         |
| -------------------- | ---------- | ---------------------------- |
| **设计稿宽度** | 750px      | 以 iPhone 6/7/8 为设计基准   |
| **设计稿高度** | 1334px     | 对应 iPhone 6/7/8 屏幕高度   |
| **单位换算**   | 1px = 1rpx | 设计稿上的 1px 直接对应 1rpx |
| **适配机制**   | rpx 自适应 | 微信自动根据屏幕宽度换算     |

### 1.2 rpx 单位说明

- **定义**：rpx (responsive pixel) 是微信小程序的响应式尺寸单位
- **原理**：规定屏幕宽度为 750rpx，在不同设备上自动换算
- **换算公式**：`1rpx = (屏幕逻辑宽度 / 750) × 1px`
- **常用设备换算对照**：

| 设备              | 逻辑宽度 | 1rpx 对应 px | 750rpx 对应 |
| ----------------- | -------- | ------------ | ----------- |
| iPhone 5/SE       | 320px    | 0.42px       | 320px       |
| iPhone 6/7/8      | 375px    | 0.5px        | 375px       |
| iPhone X/11/12/13 | 390px    | 0.52px       | 390px       |
| iPhone 14 Pro Max | 430px    | 0.57px       | 430px       |
| 安卓常见（360px） | 360px    | 0.48px       | 360px       |
| 安卓常见（412px） | 412px    | 0.55px       | 412px       |

### 1.3 字体单位使用规范

| 使用场景                   | 推荐单位 | 说明               |
| -------------------------- | -------- | ------------------ |
| 正文、标题、标签等视觉尺寸 | rpx      | 随屏幕宽度等比缩放 |
| 输入框文本、固定尺寸元素   | px       | 保持物理尺寸稳定   |
| 边框、分隔线               | rpx      | 使用 1rpx 或 2rpx  |
| 图标尺寸                   | rpx      | 随屏幕等比缩放     |

> **重要**：本项目设计稿为 750px 基准，所有视觉尺寸单位统一使用 rpx。
> 在 SCSS 中无需进行额外单位换算，设计稿标注值直接填入即可。

## 2. 页面区域划分

### 2.1 标准页面结构

一个标准微信小程序页面在垂直方向由以下区域组成：

```
┌──────────────────────────────────┐
│  [状态栏] 系统状态栏              │ 固定高度
├──────────────────────────────────┤
│  [导航栏] 自定义/原生导航栏       │ 固定高度
├──────────────────────────────────┤
│  [内容区] 主内容区域              │ 可滚动 / 固定
│          （ScrollView 或流式布局） │
│                                   │
│                                   │
├──────────────────────────────────┤
│  [操作栏] 底部固定操作按钮（可选） │ 固定高度
├──────────────────────────────────┤
│  [TabBar] 底部标签栏（L1页面专属）│ 固定高度
│  [安全区] iPhone Home Indicator   │ env(safe-area-inset-bottom)
└──────────────────────────────────┘
```

### 2.2 各区域高度标准

| 区域                   | 高度（rpx） | 高度（px iOS）   | 高度（px Android） | 说明                                                  |
| ---------------------- | ----------- | ---------------- | ------------------ | ----------------------------------------------------- |
| **状态栏**       | 动态获取    | ~44px            | ~24px              | 通过 `uni.getSystemInfoSync().statusBarHeight` 获取 |
| **原生导航栏**   | 128rpx      | 44px + statusBar | 48px + statusBar   | `navigationBarHeight`                               |
| **自定义导航栏** | 动态计算    | statusBar + 44px | statusBar + 48px   | 需通过 JS 动态适配                                    |
| **内容区**       | 剩余高度    | flex:1           | flex:1             | 占满剩余垂直空间                                      |
| **底部操作栏**   | 100~120rpx  | ~50px            | ~50px              | 按需使用                                              |
| **底部 TabBar**  | 100rpx      | ~50px            | ~50px              | 仅 L1 页面使用                                        |
| **底部安全区**   | 0~68rpx     | 34px (iPhone X+) | 0~48px             | `env(safe-area-inset-bottom)`                       |

## 3. 导航栏布局规范

### 3.1 原生导航栏

| 属性     | 标准值                    | 说明                   |
| -------- | ------------------------- | ---------------------- |
| 高度     | 128rpx                    | 包含状态栏 + 标题栏    |
| 标题字号 | 34rpx                     | Medium(500) 字重       |
| 标题颜色 | `#1A1A2E` / `#FFFFFF` | 取决于背景色           |
| 背景色   | 可自定义                  | 本项目使用 `#2B6DE8` |
| 返回按钮 | 默认样式                  | 使用 uni-app 原生返回  |

### 3.2 自定义导航栏（L1 页面）

当使用自定义导航栏时，需通过 `navigationStyle: "custom"` 配置隐藏原生导航栏。

**高度计算**：

```javascript
const systemInfo = uni.getSystemInfoSync()
const statusBarHeight = systemInfo.statusBarHeight  // px
const navBarHeight = 44  // px 标题栏高度
const totalNavHeight = statusBarHeight + navBarHeight  // px
const totalNavHeightRpx = (totalNavHeight / systemInfo.screenWidth) * 750  // rpx
```

**布局结构**：

```
┌──────────────────────────────────┐
│  [状态栏占位] padding-top        │ statusBarHeight
├──────────────────────────────────┤
│  [导航栏内容区] Flexbox          │ 44px / 48px
│   ← 返回/Logo   标题   右侧操作 → │
└──────────────────────────────────┘
```

**本项目 L1-01 首页自定义导航栏布局**：

```
┌──────────────────────────────────┐
│  [状态栏占位]                     │ statusBarHeight
├──────────────────────────────────┤
│  [导航栏] display:flex           │ 88rpx
│   ├── OA 品牌 Logo + 标题文案     │
│   └── 通知铃铛图标（带红点徽标）   │
└──────────────────────────────────┘
```

### 3.3 小程序菜单（右上角胶囊按钮）

- 所有页面右上角固定显示微信官方菜单
- 开发者不可自定义，仅可选择**深色/浅色**两种配色
- 设计时需预留该区域空间（右侧约 180rpx）
- 该区域附近避免放置可交互元素，防止交互冲突

### 3.4 导航栏设计规范

| 规范项       | 要求                                           |
| ------------ | ---------------------------------------------- |
| 导航清晰度   | 用户需明确知道"当前在哪、可以去哪、如何返回"   |
| 次级页面     | 左上角必须提供返回上一级页面操作               |
| 自有导航样式 | 需与微信官方菜单样式保持一定差异               |
| 导航数量     | 页面内标签分页（Tab）不超过 5 项，建议 ≤ 4 项 |
| 页面深度     | 不超过 5 层，建议核心流程在 3 层内完成         |

## 5. 内容区布局规范

### 5.1 内容区布局模型

本项目内容区遵循**卡片式垂直流式布局**，核心规则：

1. **页面左右边距**：统一 24rpx
2. **卡片间距**：20rpx（卡片之间垂直间距）
3. **卡片内边距**：24rpx（内容与卡片边框）
4. **卡片圆角**：16rpx（`--radius-lg`）
5. **内容区背景**：`#F7F7F7`（`--bg-page`）
6. **卡片背景**：`#FFFFFF`（`--bg-card`）

### 5.2 内容区宽度计算

```
屏幕总宽度: 750rpx
左右边距: 24rpx × 2 = 48rpx
卡片可用宽度: 750 - 48 = 702rpx
卡片左右内边距: 24rpx × 2 = 48rpx
内容实际宽度: 702 - 48 = 654rpx
```

### 5.3 内容区安全区域

```
┌─── 24rpx ────────────────── 24rpx ───┐
│        ┌─── 卡片 ───────────┐         │
│        │   24rpx 内边距     │         │
│        │   ┌─ 内容区 ──┐   │         │
│        │   │  654rpx   │   │         │
│        │   └───────────┘   │         │
│        └───────────────────┘         │
│           20rpx 卡片间距               │
│        ┌─── 卡片 ───────────┐         │
│        └───────────────────┘         │
└──────────────────────────────────────┘
```

## 10. 安全区域适配规范

### 10.1 CSS 环境变量

微信小程序基于 WebView（X5 内核），支持标准 CSS 环境变量：

| 变量                            | 说明                   | 典型值（iOS） | 典型值（安卓） |
| ------------------------------- | ---------------------- | ------------- | -------------- |
| `env(safe-area-inset-top)`    | 顶部安全区域（状态栏） | ~44px         | ~24px          |
| `env(safe-area-inset-bottom)` | 底部安全区域           | ~34px         | 0~48px         |
| `env(safe-area-inset-left)`   | 左侧安全区域           | 0             | 0              |
| `env(safe-area-inset-right)`  | 右侧安全区域           | 0             | 0              |

### 10.2 适配策略

#### 沉浸式页面（自定义导航栏）

```scss
.page {
  display: flex;
  flex-direction: column;
  min-height: 100vh;
  padding-top: env(safe-area-inset-top);
  padding-bottom: env(safe-area-inset-bottom);
  box-sizing: border-box;
}

.navbar {
  height: calc(88rpx + env(safe-area-inset-top));
  padding-top: env(safe-area-inset-top);
}
```

#### 底部固定元素（TabBar / 操作栏）

```scss
.tab-bar {
  padding-bottom: env(safe-area-inset-bottom);
}

.action-bar {
  padding-bottom: calc(20rpx + env(safe-area-inset-bottom));
}
```

### 10.3 安全区域适配要点

| 场景          | 适配方式                                            | 优先级 |
| ------------- | --------------------------------------------------- | ------ |
| 自定义导航栏  | 动态获取 `statusBarHeight` + JS 计算              | 必须   |
| 底部 TabBar   | CSS `env(safe-area-inset-bottom)`                 | 必须   |
| 底部操作栏    | CSS `env(safe-area-inset-bottom)`                 | 必须   |
| 全屏弹窗      | 避开底部安全区域                                    | 建议   |
| 吸顶/吸底元素 | 使用 `position: sticky` 或 `fixed` 并适配安全区 | 建议   |

## 12. 布局模式与排版规则

### 12.1 Flexbox 布局（首选方案）

Flexbox 是微信小程序布局的核心方案，解决 80% 的布局问题。

#### 常用模式

| 模式               | CSS 代码                                                         | 适用场景       |
| ------------------ | ---------------------------------------------------------------- | -------------- |
| **水平居中** | `display: flex; justify-content: center;`                      | 按钮、标题居中 |
| **垂直居中** | `display: flex; align-items: center;`                          | 导航栏图标对齐 |
| **完全居中** | `display: flex; justify-content: center; align-items: center;` | 弹窗内容居中   |
| **两端对齐** | `display: flex; justify-content: space-between;`               | 导航栏左右元素 |
| **等分布局** | `flex: 1`                                                      | 统计面板三等分 |
| **流式换行** | `display: flex; flex-wrap: wrap;`                              | 标签列表       |

#### 本项目 Flexbox 应用示例

```scss
// 导航栏 - 两端对齐
.nav-bar {
  display: flex;
  align-items: center;
  justify-content: space-between;
}

// 统计面板 - 等分
.stats-row {
  display: flex;
  
  .stat-item {
    flex: 1;  // 四等分
    display: flex;
    flex-direction: column;
    align-items: center;
  }
}
```

### 12.2 Grid 网格布局

Grid 适用于二维布局场景。

| 模式                 | CSS 代码                                  | 适用场景          |
| -------------------- | ----------------------------------------- | ----------------- |
| **等宽多列**   | `grid-template-columns: repeat(4, 1fr)` | 快捷入口 4 列网格 |
| **固定列数**   | `grid-template-columns: repeat(2, 1fr)` | 功能入口 2 列网格 |
| **自定义间距** | `gap: 16rpx`                            | 网格项间距        |

### 12.3 Position 定位

| 定位方式     | 适用场景                 | 说明               |
| ------------ | ------------------------ | ------------------ |
| `relative` | 作为 absolute 的参照容器 | 图标徽标容器       |
| `absolute` | 角标、徽标、悬浮按钮     | 通知红点、关闭按钮 |
| `fixed`    | 底部固定元素             | TabBar、操作栏     |
| `sticky`   | 吸顶/吸底                | 分类标题           |

### 12.4 内容排版规则

#### 文字对齐

## 13. 大屏适配规范

### 13.1 适配原则

| 原则               | 说明                                 |
| ------------------ | ------------------------------------ |
| **信息完整** | 视图信息完整可读，不能出现形变、缺失 |
| **交互流畅** | 大屏可展现更多信息，切换过程流畅     |
| **布局伸缩** | 元素宽度等比伸缩，固定最大宽度       |

### 13.2 适配策略

本项目为移动优先的微信小程序，大屏（平板/PC）适配策略：

| 适配方式               | 实现方案                       | 适用场景     |
| ---------------------- | ------------------------------ | ------------ |
| **最大宽度限制** | 设置容器 `max-width: 750rpx` | 整体页面容器 |
| **左右留白**     | 大屏时增加左右边距             | 页面内容区   |
| **网格扩展**     | 大屏增加网格列数               | 功能入口网格 |
| **百分比宽度**   | 使用 `%` 替代固定 `rpx`    | 自适应元素   |

### 13.3 大屏布局示例

```scss
// 页面容器最大宽度限制
.page-container {
  width: 100%;
  max-width: 750rpx;  // 大屏时居中显示
  margin: 0 auto;
}

// 大屏时快捷入口扩展到更多列
.quick-grid {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  
  @media (min-width: 500px) {
    grid-template-columns: repeat(5, 1fr);
  }
}
```
