# 色彩系统详细色板

## 主色

| 令牌 | 色值 | 用途 |
|------|------|------|
| 高效蓝 | `#2B6DE8` | 主色：按钮、Tab 激活、选中态、统计数字 |
| 高效蓝浅 | `#5B8DF0` | 渐变终点、hover 态 |
| 高效蓝深 | `#1A4FC7` | 按钮按压态 |

## Ardot fills 格式

```javascript
// 纯色
fills: [{type: "SOLID", color: {r: 0.169, g: 0.427, b: 0.91}, opacity: 1, visible: true, blendMode: "NORMAL"}]

// 渐变（NavBar 旧版，已废弃）
fills: [{type: "GRADIENT_LINEAR", gradientStops: [
  {color: {r: 0.08, g: 0.3, b: 0.78}, position: 0, boundVariables: {}},
  {color: {r: 0.18, g: 0.42, b: 0.9}, position: 1, boundVariables: {}}
], gradientTransform: [[1,0,0],[0,1,0]], opacity: 1, visible: true, blendMode: "NORMAL"}]
```
