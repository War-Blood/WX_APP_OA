# Code Review 检查清单

> 本清单用于代码审查时逐项核对，确保代码质量和一致性。

---

## 一、功能正确性

- [ ] 代码实现与需求文档一致
- [ ] 边界条件已处理（空值、越界、异常输入）
- [ ] 状态机转换正确
- [ ] 事务管理正确（失败时回滚）

## 二、代码质量

### 结构与设计
- [ ] 符合分层架构（routes → controllers → services → db）
- [ ] 无跨层调用
- [ ] 函数/方法职责单一
- [ ] 无重复代码块（DRY 原则）

### 复杂度
- [ ] 函数圈复杂度 ≤ 10
- [ ] 单函数行数 ≤ 100
- [ ] 无深层嵌套（最多 4 层缩进）
- [ ] 无过度设计

## 三、安全性

- [ ] SQL 使用参数化查询
- [ ] 用户输入经过校验
- [ ] JWT 验证正确实施
- [ ] 无硬编码密钥/密码
- [ ] API 权限校验覆盖

## 四、性能

- [ ] 数据库查询有合适索引
- [ ] N+1 查询已优化
- [ ] 热点数据有缓存策略

## 五、可维护性

- [ ] 公共函数有 JSDoc
- [ ] 复杂逻辑有行注释
- [ ] 无 `console.log` / `debugger`
- [ ] 无注释掉的死代码

## 六、测试

- [ ] 新功能有对应单元测试
- [ ] Bug 修复有对应回归测试
- [ ] 核心逻辑覆盖率 ≥ 60%

---

## 审查结论

| 结论 | 条件 |
|------|------|
| ✅ 通过 | 所有必检项通过，建议项 ≤ 2 项未通过 |
| ⚠️ 有条件通过 | 仅建议项未通过，已记录待处理 |
| ❌ 退回 | 存在功能/安全/质量必检项未通过 |
