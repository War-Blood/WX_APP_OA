# 定时任务

## 概述

定时任务基于 `node-cron` 实现，位于 `src/common/tasks/` 目录下，由 `scheduler.js` 统一调度。

## 现有任务

| 任务文件 | 调度表达式 | 说明 | 状态 |
|---------|-----------|------|------|
| `reminder.task.js` | `0 9 * * *` | 每天早上9点发送日报提醒 | ✅ 可用 |
| `compliance.task.js` | `0 0 * * *` | 每天零点执行合规检查 | ✅ 可用 |

## 表达式说明

```
* * * * *
┬ ┬ ┬ ┬ ┬
│ │ │ │ └── 星期 (0-7, 0/7=周日)
│ │ │ └──── 月份 (1-12)
│ │ └────── 日期 (1-31)
│ └──────── 小时 (0-23)
└────────── 分钟 (0-59)
```

## 添加新任务

1. 在 `src/common/tasks/` 下创建 `{name}.task.js`
2. 参考以下模板：

```javascript
const cron = require('node-cron');

const task = cron.schedule('0 9 * * *', async () => {
  try {
    // 任务逻辑
    console.log(`[Task] ${new Date().toISOString()} - 执行完成`);
  } catch (error) {
    console.error(`[Task] 执行失败:`, error);
  }
});

module.exports = task;
```

3. 在 `scheduler.js` 中注册新任务
