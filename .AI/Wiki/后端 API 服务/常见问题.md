# 后端常见问题

## 安装与配置

### Q: 后端启动报 "Cannot find module xxx"
**A**: 未安装依赖，运行 `npm install`。如果已安装，检查 `package.json` 中是否声明了该依赖。

### Q: 数据库连接失败
**A**: 检查以下项：
1. `.env` 中数据库配置是否正确（host/port/user/password/database）
2. MySQL 服务是否已启动
3. 防火墙是否放通了数据库端口

---

## 运行时错误

### Q: 接口返回 401 Unauthorized
**A**: JWT token 缺失或已过期。检查：
1. 请求头是否携带 `Authorization: Bearer <token>`
2. token 是否在有效期内（默认 7 天）
3. 用户是否已被删除或禁用

### Q: 接口返回 500 Internal Server Error
**A**: 服务端异常。查看 PM2 日志：
```bash
pm2 logs your-app-name --lines 50
```

### Q: 数据库查询报 "Unknown column"
**A**: 表结构未更新。运行最新的迁移脚本：
```bash
mysql -u root -p wx_app_oa < sql/migrations/NNN_description.sql
```

---

## 性能问题

### Q: API 响应慢
**A**: 检查：
1. 数据库查询是否有索引 — 运行 `EXPLAIN SELECT ...`
2. 是否有 N+1 查询问题
3. Redis 缓存是否命中

### Q: PM2 进程频繁重启
**A**: 检查内存使用：
```bash
pm2 monit
```
如果内存持续增长，可能存在内存泄漏。
