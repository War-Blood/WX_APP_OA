# 数据库查询优化指南

## 索引优化

### 常见索引类型

| 索引类型 | 说明 | 使用场景 |
|---------|------|---------|
| PRIMARY KEY | 主键索引 | 唯一标识一行 |
| INDEX | 普通索引 | 频繁查询的字段 |
| UNIQUE INDEX | 唯一索引 | 需要唯一约束的字段 |
| COMPOSITE INDEX | 复合索引 | 多条件查询（最左前缀原则） |

### 索引建议

```sql
-- 频繁按 user_id 查询 → 加索引
CREATE INDEX idx_user_id ON daily_project_progress(user_id);

-- 频繁按 status + create_time 排序 → 复合索引
CREATE INDEX idx_status_time ON daily_project_progress(status, create_time);
```

## 查询优化

### 避免 SELECT *
```sql
-- 不推荐
SELECT * FROM users;

-- 推荐（只取需要的字段）
SELECT openid, nickname, avatar FROM users;
```

### 使用分页
```sql
-- 不推荐（全量加载）
SELECT * FROM daily_project_progress;

-- 推荐（分页）
SELECT * FROM daily_project_progress
ORDER BY create_time DESC
LIMIT 20 OFFSET 0;
```

### 避免 N+1
```sql
-- 不推荐（循环查询）
for (const id of ids) {
  await db.query('SELECT * FROM users WHERE id = ?', [id]);
}

-- 推荐（一次查询）
await db.query('SELECT * FROM users WHERE id IN (?)', [ids]);
```

## 慢查询排查

```sql
-- 查看慢查询日志是否开启
SHOW VARIABLES LIKE 'slow_query_log';

-- 查看慢查询阈值
SHOW VARIABLES LIKE 'long_query_time';

-- 分析查询计划
EXPLAIN SELECT * FROM daily_project_progress WHERE status = 'pending';
```

**EXPLAIN 输出关键字段**:
- `type`: `ALL`（全表扫描）→ 需优化；`ref`/`range` → 良好；`const` → 最优
- `rows`: 扫描行数，越小越好
- `Extra`: `Using filesort` → 需加排序索引；`Using temporary` → 需优化
