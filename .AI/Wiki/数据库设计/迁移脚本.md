# 数据库迁移脚本

## 迁移规范

- 迁移脚本存放在 `sql/migrations/` 目录下
- 文件名格式: `NNN_description.sql`（NNN 为递增序号）
- 每个脚本只做一件事（新增表 / 修改字段 / 添加索引）
- 脚本需支持重复执行（`IF NOT EXISTS` / `IF EXISTS`）

## 执行方式

### 本地开发
```bash
mysql -u root -p wx_app_oa < sql/migrations/NNN_description.sql
```

### 生产环境
```bash
mysql -h 111.229.107.123 -u admin -p wx_app_oa < sql/migrations/NNN_description.sql
```

## 编写规范

```sql
-- ========================================
-- Migration NNN: 描述
-- 日期: YYYY-MM-DD
-- ========================================

-- UP: 新增表
CREATE TABLE IF NOT EXISTS `xxx` (
  `id` INT AUTO_INCREMENT PRIMARY KEY,
  `name` VARCHAR(100) NOT NULL,
  `created_at` DATETIME DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- DOWN: 回滚脚本
-- DROP TABLE IF EXISTS `xxx`;
```
