# 数据库常见问题

## 连接问题

### Q: "Too many connections" 错误
**A**: 连接池耗尽。检查：
1. `config/database.js` 中的 `connectionLimit` 配置
2. 是否有查询未正确释放连接（`pool.release()` 或 `pool.end()`）
3. MySQL 最大连接数：
```sql
SHOW VARIABLES LIKE 'max_connections';
```

### Q: 跨库查询报错
**A**: 跨库查询需使用完整表名 `database.table`：
```sql
SELECT * FROM wx_app_oa.users u
JOIN daily_report.daily_project_progress d ON u.openid = d.user_id
```

## 性能问题

### Q: 查询慢
**A**: 使用 EXPLAIN 分析：
```sql
EXPLAIN SELECT * FROM daily_project_progress WHERE user_id = 'xxx';
```
检查 `type` 列是否为 `ALL`（全表扫描），是则需加索引。

### Q: 死锁
**A**: 检查事务顺序是否一致。确保多个事务以相同的顺序访问表和行。

---

## 数据问题

### Q: 数据乱码
**A**: 检查字符集配置：
```sql
SHOW VARIABLES LIKE 'character_set%';
```
确保数据库、表、连接均为 `utf8mb4`。

### Q: 主键冲突
**A**: 检查自增 ID 是否达到上限，或是否在导入数据时指定了已存在的 ID。
