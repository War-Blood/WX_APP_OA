# 部署常见问题

## 服务器连接

### Q: SSH 连接失败
**A**: 检查：
1. 服务器是否开机且网络正常
2. SSH 密钥路径是否正确（`C:\Users\WarBlood\.ssh\wx_app_key.pem`）
3. 密钥权限是否 600（Windows 下通常不需要设置）
4. 连接命令: `ssh -i "C:\Users\WarBlood\.ssh\wx_app_key.pem" ubuntu@111.229.107.123`

### Q: 端口无法访问
**A**: 检查：
1. 腾讯云安全组是否放通了对应端口
2. Nginx 配置是否正确
3. 进程是否在监听：`sudo netstat -tlnp | grep :PORT`

## 进程管理

### Q: PM2 进程挂了
**A**: 查看日志定位原因：
```bash
pm2 logs your-app --lines 100
```
常见原因：端口被占用、内存不足、代码运行时错误。

### Q: PM2 重启后服务还是旧的
**A**: 确保重启后更新了代码：
```bash
git pull origin main     # 拉取最新代码
npm install              # 更新依赖（如有变更）
pm2 restart your-app     # 重启进程
```

## Nginx

### Q: 502 Bad Gateway
**A**: 后端服务未启动或端口不通：
```bash
pm2 list                 # 确认进程运行状态
curl localhost:3000/api/health  # 测试本地端口
```

### Q: SSL 证书过期
**A**: 使用 certbot 续期：
```bash
sudo certbot renew --nginx
```
建议设置定时任务自动续期。
