# 测试常见问题

## 环境配置

### Q: 测试报 "Cannot find module 'supertest'"
**A**: 运行 `npm install` 安装测试依赖。

### Q: 测试数据库连接失败
**A**: 测试使用独立的测试数据库配置。检查：
1. `.env.test` 文件是否存在且配置正确
2. MySQL 服务是否启动
3. 测试数据库是否已创建

---

## 测试编写

### Q: 测试报超时
**A**: API 测试默认超时 10000ms。如果后端响应慢，可在测试中增加超时：
```javascript
jest.setTimeout(30000);
```

### Q: 测试之间互相影响
**A**: 确保测试使用 `beforeEach` / `afterEach` 清理测试数据：
```javascript
beforeEach(async () => {
  await db.query('DELETE FROM test_table');
});
```

---

## 覆盖率

### Q: 覆盖率不达标
**A**: 检查 `jest.config.js` 中的 `collectCoverageFrom` 配置，确保目标文件被包含在覆盖率统计中。

### Q: 如何查看覆盖率报告
**A**: 运行 `npm run test -- --coverage`，报告生成在 `coverage/` 目录下，打开 `coverage/lcov-report/index.html` 查看可视化报告。
