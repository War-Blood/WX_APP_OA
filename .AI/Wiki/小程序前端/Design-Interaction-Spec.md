## 1. 设计系统总览

### 1.1 画板与适配

| 项目 | 设计稿(px) | 小程序(rpx) | 说明 |
|------|----------|-----------|------|
| 画板尺寸 | 375 × 812 | 750 × 1624 | iPhone X 标准 |
| 换算比 | 1px = 2rpx | — | 基于 750rpx 设计宽度 |
| Status Bar | 44px | 88rpx | `--status-bar-height` |
| NavBar | 44px | 88rpx | `--nav-bar-height` |
| TabBar | 50px | 100rpx | + `safe-area-inset-bottom` |
| 底部操作栏 | 60-64px | 120-128rpx | L3 页专用 |

### 1.2 页面布局公式

#### L1 首页（含 TabBar）

```
┌─ Status  44px 白 ────────────────────┐
├─ NavBar  44px 白 ────────────────────┤
├─ Content layoutGrow:1 ───────────────┤
├─ TabBar  50px 白 ────────────────────┤
└───────────────────────────────────────┘
  812 = 44 + 44 + 674 + 50
```

**设计稿参考**:
- `primaryAxisSizingMode: "FIXED"` + `layoutGrow: 1` 填充 Content
- `clipsContent: true` 防止溢出
- TabBar 固定 `layoutGrow: 0`

#### L2 列表页（无 TabBar）

```
┌─ Status  44px 白 ────────────────────┐
├─ NavBar  44px 白 ← 标题 ── 操作 ────┤
├─ Content layoutGrow:1 ───────────────┤
└───────────────────────────────────────┘
  812 = 44 + 44 + 724
```

**设计稿参考**:
- NavBar 左侧返回箭头(←)，右侧可选操作图标
- Content 区可滚动，`layoutGrow: 1` + `primaryAxisSizingMode: "FIXED"`

#### L3 详情/编辑页（含底部操作栏）

```
┌─ Status  44px 白 ────────────────────┐
├─ NavBar  44px 白 ← 标题 ─────────────┤
├─ Content layoutGrow:1 (FIXED) ───────┤
├─ 底部操作 60-64px 白 ────────────────┤
└───────────────────────────────────────┘
  812 = 44 + 44 + Content + 底部操作
```

**设计稿参考**:
- 底部操作栏 `layoutGrow: 0`，固定在底部
- Content 区 `layoutGrow: 1` + `primaryAxisSizingMode: "FIXED"` 自适应
- 底部按钮永远使用固定宽度（A/C 类 351px, B 类 165-166px）
