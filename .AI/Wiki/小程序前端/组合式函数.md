# 组合式函数

## 概述

组合式函数（Composables）是基于 Vue 3 Composition API 的逻辑复用方案，位于 `src/composables/` 目录下。

## 现有函数

| 函数名 | 文件 | 说明 | 状态 |
|--------|------|------|------|
| `useAuth` | `useAuth.js` | 用户认证状态管理 | ✅ 可用 |
| `usePagination` | `usePagination.js` | 分页逻辑封装 | ✅ 可用 |

## useAuth

```javascript
import { useAuth } from '@/composables/useAuth'

const { isLoggedIn, userInfo, login, logout } = useAuth()
```

| 返回 | 类型 | 说明 |
|------|------|------|
| `isLoggedIn` | `ref<boolean>` | 是否已登录 |
| `userInfo` | `ref<Object>` | 用户信息 |
| `login` | `Function` | 登录（调用 wx.login + 后端 API） |
| `logout` | `Function` | 退出登录 |

## usePagination

```javascript
import { usePagination } from '@/composables/usePagination'

const { list, loading, hasMore, loadMore, refresh } = usePagination(fetchApi)
```

| 返回 | 类型 | 说明 |
|------|------|------|
| `list` | `ref<Array>` | 数据列表 |
| `loading` | `ref<boolean>` | 加载状态 |
| `hasMore` | `ref<boolean>` | 是否还有更多数据 |
| `loadMore` | `Function` | 加载下一页 |
| `refresh` | `Function` | 刷新列表 |
