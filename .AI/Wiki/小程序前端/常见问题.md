# 小程序常见问题

## 开发环境

### Q: 编译报 "node_modules 缺少编译器模块"
**A**: 依赖安装不完整，运行：
```bash
cd miniapp && npm install
```
如果问题持续，删除 `node_modules` 和 `package-lock.json` 后重试。

### Q: 小程序开发工具预览空白
**A**: 检查：
1. 是否运行了 `npm run dev:mp-weixin`
2. 开发者工具是否选择了正确的项目目录（`miniapp/dist/dev/mp-weixin`）
3. 控制台是否有网络请求错误

---

## API 对接

### Q: 接口返回 401
**A**: token 失效，检查：
1. `services/request.js` 中是否正确设置了 Authorization header
2. 用户登录状态是否过期
3. 是否在 `onShow` 中重新检查了登录状态

### Q: 接口返回数据格式不对
**A**: 检查 `services/modules/xxx.js` 中的字段映射是否与后端 API 文档一致。如果确定是后端问题，直接指出不强行适配。

---

## 样式问题

### Q: iPhone 底部安全区域适配
**A**: 使用 CSS 环境变量：
```css
padding-bottom: constant(safe-area-inset-bottom);
padding-bottom: env(safe-area-inset-bottom);
```

### Q: 页面下拉刷新不生效
**A**: 检查是否在页面配置中开启了 `enablePullDownRefresh`，以及是否使用了 `refresher` 组件方案。
