## 1. 设计概述

### 1.1 设计目标

- **一致性**：统一 WE UI 浅色设计语言，NavBar 蓝渐变、TabBar 胶囊式3Tab、内容区白色背景无卡片阴影
- **效率优先**：以「高效办公」为核心设计理念，减少操作步骤，优化任务流程 — 首页工作台聚合所有高频操作入口
- **品牌强化**：高效蓝（#2B6DE8）贯穿全局，从导航栏到按钮到 Tab 选中态，强化品牌识别
- **移动优先**：基于微信小程序移动端特性，所有操作区域集中在屏幕下半区，单手可达

### 1.2 设计原则

| 原则 | 说明 | 实际体现 |
|------|------|---------|
| **清晰** | 每个页面只有一个核心任务，信息层级分明 | 首页聚合待办/入口/动态；功能中心按业务分组；个人中心个人信息+设置 |
| **轻量** | WE UI 浅色风格，无卡片阴影，分割线区分内容区域 | 内容区白色背景 + 灰色分割线 + 圆角图标 |
| **高效** | 高频操作集中在易触达区域 | 首页底部待办、快捷入口、导航栏通知/设置按钮 |
| **反馈** | 每次操作有即时反馈 | hover 态背景变色、点击态缩放、下拉刷新动画、Toast 提示 |
| **容错** | 关键操作需二次确认 | 退出登录 uni.showModal 弹窗确认 |

### 1.3 页面层级定义

| 层级 | 定义 | 当前数量 | 示例 |
|------|------|---------|------|
| **L1** | 主Tab页，底部导航栏直接访问 | 3 | 首页、功能中心、个人中心 |
| **L2** | 功能模块首页/列表页，从L1或功能入口跳转 | 1（已实现） | 审批中心 |
| **L3** | 详情/编辑页，从L2列表项跳转 | 0（待创建） | 审批详情、日报编辑 |
| **L4** | 操作弹窗/浮层，临时性交互 | 0（待创建） | 确认弹窗、意见输入面板 |

## 4. 页面交互设计

### 4.1 通用交互行为

#### 4.1.1 页面结构模式

```
每个页面统一结构：
┌──────────────────────────────────┐
│    NavBar（蓝渐变/白色导航栏）    │  ← 固定顶部
├──────────────────────────────────┤
│                                  │
│     scroll-view 可滚动内容区      │  ← flex: 1; height: 0
│     ┌─────────────────────┐      │
│     │  白色卡片内容块       │      │
│     └─────────────────────┘      │
│     ┌─────────────────────┐      │
│     │  白色卡片内容块       │      │
│     └─────────────────────┘      │
│                                  │
├──────────────────────────────────┤
│     TabBar（底部导航栏）         │  ← 固定底部（L1页面）
└──────────────────────────────────┘
```

#### 4.1.2 下拉刷新行为

| 触发区域 | 首页内容区域 |
|---------|-------------|
| **实现方式** | scroll-view refresher-enabled |
| **刷新指示** | 微信原生下拉刷新指示器 |
| **刷新逻辑** | 重新随机生成统计数据，1秒后结束，显示 Toast "刷新成功" |
| **触发时机** | 手指下拉超过阈值松手 |

#### 4.1.3 上拉加载行为

| 触发区域 | 首页最近动态列表底部 |
|---------|-------------------|
| **触发方式** | scroll-view scrolltolower 事件 |
| **加载指示** | 旋转动画 + "加载中..." 文字 |
| **完成状态** | 显示 "已经到底啦" 文字 |
| **加载逻辑** | 模拟1秒延迟，之后标记无更多数据 |

#### 4.1.4 列表项交互
