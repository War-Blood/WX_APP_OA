# 里程碑规划

## 总体规划

| 里程碑 | 阶段 | 状态 | 预计完成 | 主要交付物 |
|--------|------|:----:|:--------:|-----------|
| M0 | 项目初始化 | ✅ 已完成 | - | 项目搭建、PRD 文档、目录结构 |
| M1 | 用户与权限 | 🔜 进行中 | TBD | 登录页、用户 CRUD、部门树、角色权限 |
| M2 | 内容编排 | ⚪ 待开发 | TBD | 工作台配置、模块开关 |
| M3 | 审批管理 | ⚪ 待开发 | TBD | 模板设计器、审批实例管理 |
| M4 | 仪表盘与日报 | ⚪ 待开发 | TBD | 数据看板、审核统计 |
| M5 | 系统运维 | ⚪ 待开发 | TBD | 安全策略、操作日志、系统配置 |
| M6 | 项目与资产 | ⚪ 待开发 | TBD | 项目看板、资产台账 |
| M7 | 公告与消息 | ⚪ 待开发 | TBD | 公告发布、消息推送 |
| M8 | 集成测试与优化 | ⚪ 待开发 | TBD | E2E 测试、性能优化、体验优化 |

## M1 详细任务

| 任务 | 优先级 | 说明 |
|------|:------:|------|
| 登录页面 | P0 | 管理员账号密码登录 |
| 用户管理 CRUD | P0 | 用户列表、新增、编辑、删除 |

| 角色权限管理 | P1 | 角色 CRUD、权限分配 |
