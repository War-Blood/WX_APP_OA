# Web 管理后台 — 文档索引

## 模块说明

Web 管理后台基于 Vue 3 + TypeScript + Element Plus 构建，采用 Pinia 管理状态，Vue Router 处理路由。

## 开发阶段里程碑

| 里程碑 | 阶段 | 状态 | 主要交付物 |
|--------|------|------|-----------|
| M0 | 项目初始化 | ✅ 已完成 | 项目搭建、PRD 文档、目录结构 |
| M1 | 用户与权限 | 🔜 进行中 | 登录页、用户 CRUD、部门树、角色权限 |
| M2 | 内容编排 | ⚪ 待开发 | 工作台配置、模块开关 |
| M3-M8 | 后续阶段 | ⚪ 待开发 | 审批/仪表盘/运维/项目/公告等 |
