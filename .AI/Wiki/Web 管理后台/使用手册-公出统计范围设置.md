# 使用手册 — 公出统计范围设置

> 适用范围：管理员（admin/superadmin）
> 功能版本：2026-08-12 起

## 一、功能说明

公出统计（小程序「公出统计」页 + Web「报表/公出统计」各页面）的人员显示范围**默认只显示「浙江贝良」部门树下、需要提交公出日志的现场作业人员**。

系统管理员、未分配部门、办公室/非现场岗位等**无需提交公出日志的人员不会显示**在公出统计中，也不会被计为「未提交」。

> 这是可配置的：管理员可在 Web「系统设置」中把范围改为任意部门（含其全部子部门）。

## 二、配置入口

- 路径：**Web 管理后台 → 系统设置 → 公出统计** 分组
- 权限：**管理员（admin+）** 均可查看与修改系统设置；其中「安全策略」分组（登录尝试次数/锁定时间/密码长度/会话超时）**仅超级管理员（superadmin）** 可改

## 三、配置步骤

1. 登录 Web 管理后台，进入「系统设置」页。
2. 找到「**公出统计**」分组下的「**人员范围部门**」下拉框。
3. 选择要作为统计范围的部门（默认已选「浙江贝良」）。
4. 点击「**保存配置**」并确认。
5. 保存后立即生效：小程序「公出统计」页与 Web 各统计页刷新即可看到新范围。

## 四、范围规则

| 规则 | 说明 |
| ------ | ------ |
| 部门范围 | 所选部门 + 其**全部子部门**（部门树下所有人） |
| 现场作业 | 仅 `is_field_worker = 是` 的**现场作业人员**（在「花名册」中维护） |
| 有记录 | 只显示范围内、当日/当月**存在记录**的人（提交、被代填、出差、请假等） |
| 排除对象 | 范围外部门、非现场作业人员、系统管理员、已删除/停用账号 |

### 默认范围

- 部门：**浙江贝良**（含总经办、研发中心、技术工程中心→工程部/技术部 等全部子部门）
- 人员：浙江贝良下全部**现场作业人员**（当前约 18 人，以花名册 `is_field_worker` 为准）

## 五、生效页面

范围设置对**小程序端与 Web 端所有公出统计页面**统一生效：

- 小程序「公出统计」：全员当日 / 人员分布 / 区域分布 / 日历 / 项目进展 / 人员明细
- Web 报表：人员工作类型分布 / 人员分布图 / 提交日历 / 统计概览 / 人员明细

## 六、边界与注意事项

1. **`is_field_worker` 需维护准确**：现场作业人员需在「花名册/人事」中标记为现场作业，否则不会出现在公出统计中。非现场人员即使有出差记录也不显示。
2. **改为其他部门**：如改为「工程部」，则只显示工程部及其子部门下的现场作业人员；不再包含浙江贝良其它部门。
3. **清空/停用范围**：若该配置被清空，则恢复为「不限部门」（所有非管理员、非软删用户），此时非现场人员可能重新出现——建议始终保留一个部门范围。
4. **不影响数据**：范围过滤只影响统计**展示**，不删除任何日志/人员数据。
5. **历史数据**：配置仅作用于实时统计，不回填历史展示。
6. **工作日报人员**：按当前设定，办公室人员（提交「工作日报」/office 类型）**不显示**在公出统计中；如需重新纳入，请联系开发调整配置开关。

## 七、常见问题

**Q：为什么某位现场作业人员没出现在公出统计里？**
A：检查该人员在花名册中是否标记为「现场作业」，以及其所在部门是否在所选范围内。

**Q：改了部门范围后没生效？**
A：确认保存成功（提示「配置已保存」）后刷新统计页面；小程序需重新进入页面或下拉刷新。

**Q：想把办公室人员也纳入统计？**
A：当前设计为「仅现场作业人员」。如需变更，联系开发在系统设置中增加「是否包含非现场人员」开关。

## 八、GitHub 参考案例（设计依据）

本功能采用「**筛选条件/视图配置存入数据库，后端据此过滤查询，前端免改代码**」的模式，参考以下开源项目：

- [Jet Admin / Jet Bridge](https://github.com/jet-admin/jet-bridge) — 免代码管理后台；**Segments 保存筛选集**（把一组筛选条件存为可复用段）、Dashboards 可视化配置、按任意字段筛选。
- [Motor Admin](https://github.com/zzdx713/motor-admin) — 免代码后台 + BI；**CRUD/筛选全部通过 UI 配置**、Dashboards 组合 SQL 报表、配置存数据库。
- [Payload Admin UI Pro](https://github.com/payloadcms/payload)（插件）— 管理面板完全免代码配置；Dashboard Builder 拖拽布局、**保存的筛选/视图偏好**、配置 JSON 导入导出。

## 九、后续扩展方向（免代码调整统计页）

当前已落地「公出统计人员范围部门」这一项可配置筛选。后续可沿用**同一模式**为各统计视图增加更多可配置项，均无需修改前端代码：

| 可扩展配置 | 说明 |
| ------ | ------ |
| 日期范围 | 各统计视图默认查看日期/月份可配置 |
| 工作类型 | 人员分布/全员当日按工作类型过滤 |
| 是否含非现场人员 | 切换「仅现场作业」开关 |
| 区域/省份 | 区域分布按省份范围过滤 |

> 实施方式：在系统设置新增配置键（如 `stats.xxx`），后端统计查询读取该配置作为过滤条件即可；前端统计页无需改动。
