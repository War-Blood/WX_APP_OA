# Web 管理后台常见问题

## 开发环境

### Q: npm run dev 报 TypeScript 类型错误
**A**: 运行 `npm run type-check` 查看具体错误。常见原因：
1. API 返回类型与接口定义不匹配
2. 组件 props 类型定义错误
3. 使用了 `any` 类型（应避免）

### Q: Element Plus 组件样式不生效
**A**: 检查 `main.ts` 中是否已导入 Element Plus 样式：
```typescript
import 'element-plus/dist/index.css'
```

---

## API 对接

### Q: 接口返回数据为 undefined
**A**: 检查 `src/api/xxx.ts` 中的类型定义是否与后端响应结构一致。特别留意嵌套字段的路径。

### Q: 登录后页面不跳转
**A**: 检查：
1. 登录接口是否返回了正确的 token
2. token 是否已存储到 Pinia store
3. 路由守卫（router.beforeEach）是否放行了已登录用户

---

## 构建部署

### Q: 生产构建报错
**A**: 运行 `npm run build` 前确保：
1. 所有 TypeScript 类型检查通过
2. ESLint 无错误
3. 环境变量配置正确（`.env.production`）
