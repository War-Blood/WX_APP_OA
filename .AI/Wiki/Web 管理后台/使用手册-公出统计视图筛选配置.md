# 使用手册 — 公出统计视图筛选配置

> 适用范围：管理员（admin+）
> 功能版本：2026-08-12 起

## 一、功能说明

管理员可在 Web「系统设置」中，**分别为每个公出统计视图配置筛选条件**（部门范围 / 仅现场作业 / 工作类型 / 区域省份），无需编写代码即可调整各视图展示的人员与内容范围。

配置采用「**筛选条件存数据库、后端据此过滤、前端免改代码**」的模式（参考 Jet Admin / Motor Admin / Payload，见第八节）。

## 二、配置入口与权限

- 路径：**Web 管理后台 → 系统设置 → 公出统计**
- 权限：**管理员（admin+）** 均可查看与配置；「安全策略」分组（登录尝试/锁定/密码长度/会话超时）仅**超级管理员**可改

## 三、各视图可配置项

| 视图 | 部门范围 | 仅现场作业 | 工作类型 | 区域/省份 |
|------|:---:|:---:|:---:|:---:|
| 全员当日 | ✅ | ✅ | ✅ | — |
| 人员分布 | ✅ | ✅ | ✅ | — |
| 区域分布 | ✅ | ✅ | — | ✅ |
| 提交日历 | ✅ | ✅ | — | — |
| 人员明细 | ✅ | ✅ | — | — |

> 「项目进展」为项目维度视图，不参与人员筛选配置。

## 四、筛选条件说明

- **部门范围**：所选部门 + 其**全部子部门**（未选择 = 不限部门）
- **仅现场作业**：开 = 只显示 `is_field_worker = 是` 的现场作业人员（推荐开启；办公室/管理岗不显示、不计未提交）
- **工作类型**：按 工作（陆）/ 工作（海）/ 待工 / 在途 过滤；选「全部」不过滤
- **区域/省份**：区域分布仅显示所选省份

## 五、配置步骤

1. 进入「系统设置 → 公出统计」。
2. 对每个视图设置筛选条件（部门下拉、现场开关、工作类型、省份）。
3. 点「保存配置」并确认；**立即生效**，刷新统计页查看。

## 六、生效范围

小程序「公出统计」页与 Web 报表各统计页，均按**对应视图**的配置展示。

## 七、边界与注意事项

1. `is_field_worker` 需在「花名册」中维护准确，否则现场作业人员可能不显示。
2. 各视图**独立配置**：改「全员当日」不影响「人员分布」。
3. 清空部门范围 = 不限部门，此时建议开启「仅现场作业」避免非现场人员出现。
4. 仅调整展示，不影响任何日志/人员数据。
5. 配置仅作用于实时统计，不回填历史展示。

## 八、GitHub 参考案例（设计依据）

- [Jet Admin / Jet Bridge](https://github.com/jet-admin/jet-bridge) — 免代码管理后台；**Segments 保存筛选集**、Dashboards 可视化配置、按任意字段筛选。
- [Motor Admin](https://github.com/zzdx713/motor-admin) — 免代码后台 + BI；**CRUD/筛选全部通过 UI 配置**、配置存数据库。
- [Payload Admin UI Pro](https://github.com/payloadcms/payload)（插件）— 管理面板免代码配置；Dashboard Builder、**保存的筛选/视图偏好**、配置 JSON 导入导出。

## 九、后续扩展

按同一模式可新增更多筛选项（日期范围、人员状态等）或视图，均无需修改前端代码：在系统设置新增配置键，后端统计查询读取即可。
