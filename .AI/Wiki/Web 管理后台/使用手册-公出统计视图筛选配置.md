# 使用手册 — 公出统计视图筛选

> 适用范围：管理员（admin+）
> 功能版本：2026-08-12 起

## 一、功能说明

在 **Web 报表各统计页**上提供**筛选条**，管理员可直接选择筛选条件（部门范围 / 仅现场作业 / 工作类型 / 区域省份）来设置该视图的人员数据范围，**选择即生效**并保存。**小程序「公出统计」页与 Web 报表页都按该筛选结果显示**，口径一致，无需编写代码。

> 采用「筛选条件存数据库、后端据此过滤、前端免改代码」的模式（参考 Jet Admin / Motor Admin / Payload 等，见第八节）。

## 二、筛选入口（统计页内联，非系统设置）

| 统计页（Web 报表） | 视图标识 | 筛选条控件 |
|------|------|------|
| 人员工作类型 `/report/worktype` | worktypes | 部门 + 仅现场 + 工作类型 |
| 人员分布图 `/report/distribution` | area | 部门 + 仅现场 + 省份 |
| 提交日历 `/report/calendar` | calendar | 部门 + 仅现场 |
| 人员明细 `/report/workers` | workers | 部门 + 仅现场 |
| 全员当日（小程序） | daily | 按 Web「人员分布」等设置的同一模式 |

> 月份/日期导航保持原样；筛选条只控制**人员范围**。

## 三、筛选条件说明

- **部门范围**：所选部门 + 其**全部子部门**（未选择 = 不限部门）
- **仅现场作业**：开 = 只显示 `is_field_worker = 是` 的现场作业人员（推荐开启；办公室/管理岗不显示、不计未提交）
- **工作类型**：按 工作（陆）/ 工作（海）/ 待工 / 在途 过滤；选「全部」不过滤
- **区域/省份**：区域分布仅显示所选省份

## 四、使用步骤

1. 进入 Web 报表 → 某统计页（如「人员工作类型」）。
2. 在页头筛选条选择部门 / 切换「仅现场」 / 选工作类型 / 填省份。
3. **选择即保存并刷新**该视图；小程序统计页同步显示同一结果。

## 五、生效范围

- **Web**：该统计页立即按筛选刷新。
- **小程序**：「公出统计」页各视图按同一筛选结果显示（后端统一应用）。
- 修改筛选会更新全部统计视图对应的已保存配置。

## 六、边界与注意事项

1. `is_field_worker` 需在「花名册」维护准确，否则现场作业人员可能不显示。
2. **筛选保存即全局生效**：任一管理员修改会应用到小程序与 Web 的统计展示；如需按人独立保存，可后续扩展。
3. 清空部门范围 = 不限部门，此时建议开启「仅现场作业」。
4. 仅调整展示，不影响任何日志/人员数据。
5. 代填（同事代写）人员已修复：只出现在 `workers` 文本、无关联表行的代填人员也能在统计中恢复显示，不再缺失。

## 七、GitHub 参考案例（表格筛选式）

- [pure-admin-table](https://github.com/pure-admin/pure-admin-table) — Vue3 + Element Plus 表格，列筛选插槽。
- [vue-filter-panel](https://www.npmjs.com/package/@terry0316/vue-filter-panel) — 独立筛选面板组件，列定义 + 远程搜索。
- [cx-ui33](https://www.npmjs.com/package/@kevinchang1207/cx-ui33) — 表格列原生 `filters`/`filterMethod` 筛选。
- [admin-table-page](https://www.npmjs.com/package/admin-table-page) — 列配置 `filterable`/`filterOptions` 驱动筛选。
- [everright-filter](https://www.npmjs.com/package/everright-filter) — 高级查询/筛选构建器。

## 八、后续扩展

按同一模式可新增筛选项（日期范围、人员状态等）或应用到更多视图，均无需修改前端代码：新增配置键，后端统计查询读取即可。
