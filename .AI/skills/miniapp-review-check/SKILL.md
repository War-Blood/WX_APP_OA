# 微信小程序审核合规检查

## 检查清单

逐项检查 miniapp/src/ 下所有页面，确保通过微信审核。

### 1. 死路由检查
- 所有 `.vue` 页面必须在 `pages.json` 中注册
- `pages.json` 中注册的页面文件必须存在
- 不允许路由指向不存在的页面

### 2. 功能控件响应性
- 所有 `@tap` / `@click` 绑定的函数必须存在且有效
- 所有按钮/控件必须有实际功能，点击不能无响应
- `uni.navigateTo` 的路由必须有效
- `uni.switchTab` 的 tab 页必须存在

### 3. 空 toast / 占位功能
搜索以下模式，每一项都是违规：
- `uni.showToast({ title: '功能待开发' })` — 占位 toast
- `uni.showToast({ title: '功能开发中' })` — 未完成功能
- `uni.showToast({ title: '暂未开放' })` — 虚假入口
- `route: ''` 或 `route: ""` — 空路由指向
- 模板中 `@tap="handleXxx"` 但 `handleXxx` 只弹 toast

### 4. 页面完整性
- 每个页面必须有完整的 `<template>` + `<script setup>` + `<style>`
- 不允许引用不存在的组件
- `import` 的文件路径必须存在

## 输出格式

```
## 微信审核合规报告

### 🔴 必须修复（会被拒审）
| # | 文件:行号 | 问题 | 违反条款 |
|---|---------|------|---------|
| 1 | xxx.vue:42 | 功能待开发 toast | 3.3 功能不可用 |

### 🟡 建议修复
| # | 文件:行号 | 问题 |

### 🟢 通过项
- 列出关键检查项
```

## 修复方案

对于每个 🔴 项，给出具体修复方案：
- 占位功能 → 通过模块管理设置为 `visible: false` 隐藏
- 空 toast → 改为实际功能或移除入口
- 死路由 → 注册正确路由或移除链接
