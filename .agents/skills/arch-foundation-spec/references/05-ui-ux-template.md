## 3. Webapp 端设计

### 3.1 页面 1：`<页面名>`

**页面路径**：`views/<模块>/<页面>.vue`

**布局结构（Element Plus 组件）：**

```
┌──────────────────────────────────────────────────────┐
│  ElMenu（顶部导航或侧边栏）                           │
├──────────────────────────────────────────────────────┤
│                                                      │
│  ┌────────────────────────────────────────────────┐  │
│  │  ElForm（筛选区）                                │  │
│  │  [输入框] [选择器] [日期] [查询按钮] [重置按钮]  │  │
│  └────────────────────────────────────────────────┘  │
│                                                      │
│  ┌────────────────────────────────────────────────┐  │
│  │  工具栏：[新增] [导出] [批量删除]                │  │
│  ├────────────────────────────────────────────────┤  │
│  │  ElTable（数据表格）                             │  │
│  │  ┌──┬──────┬──────┬──────┬──────┬────────┐    │  │
│  │  │☐ │ 列1   │ 列2   │ 列3   │ 状态  │ 操作    │    │  │
│  │  ├──┼──────┼──────┼──────┼──────┼────────┤    │  │
│  │  │☐ │ 值    │ 值    │ 值    │ Tag   │ 编辑 删除│    │  │
│  │  └──┴──────┴──────┴──────┴──────┴────────┘    │  │
│  ├────────────────────────────────────────────────┤  │
│  │  ElPagination（分页）                            │  │
│  └────────────────────────────────────────────────┘  │
│                                                      │
└──────────────────────────────────────────────────────┘
```

**组件使用说明：**

| 区域 | 组件 | 配置 |
|------|------|------|
| 筛选区 | ElForm | inline 模式，label-width 80px |
| 数据表格 | ElTable | stripe, border, selection |
| 分页 | ElPagination | layout: "total, sizes, prev, pager, next, jumper" |
| 操作列 | ElButton | text 类型，size small |
| 状态列 | ElTag | type 按 status 映射 |

**交互流程：**

1. 进入页面 → 触发查询 → 渲染表格
2. 点击"新增" → 打开 ElDialog → 填写表单 → 提交 → 刷新表格
3. 点击"编辑" → 打开 ElDialog（预填数据）→ 修改 → 提交 → 刷新表格
4. 点击"删除" → ElMessageBox 确认 → 调用接口 → 刷新表格
5. 筛选条件变化 → 重新查询（page 重置为 1）
