# 任务清单查看

## 触发时机

- 用户说"任务"、"任务清单"、"任务进度"
- 用户问"还有什么没做"、"还有什么待办"、"接下来做什么"
- 用户说"查看任务"、"看下进度"

## 输出路径

```
需求/任务进度/考勤模块任务清单.md
```

## 工作流程

1. **读取清单**：读取 `需求/任务进度/考勤模块任务清单.md`
2. **统计进度**：计算已完成/未完成数量（已完成 = `[x]`，未完成 = `[ ]`）
3. **展示摘要**：先展示进度概览（已完成 X/总数 Y），再按 P0→P1→P2 分组列出未完成任务
4. **建议下一步**：根据优先级推荐接下来应该做的任务

## 展示格式

```
## 任务进度概览
- 已完成: X / 总数: Y (Z%)

## P0 — 数据正确性（N 项待办）
- [ ] 任务1
- [ ] 任务2

## P1 — 功能完整性（N 项待办）
- [ ] 任务3

## P2 — 完善体验（N 项待办）
- [ ] 任务4

> 💡 建议下一步：<任务名>
```

## 注意事项

- 如果清单文件不存在，提示用户还没有任务清单
- 只展示未完成的任务，已完成的任务折叠在最后
- 任务描述保持原样，不重新组织
