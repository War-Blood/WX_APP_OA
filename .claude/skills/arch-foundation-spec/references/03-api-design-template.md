# 03-api-design — API 设计模板

> 维度：接口契约（通用约定、错误码、端点清单）
> 读者：前端开发、后端开发、测试
> 上游依赖：`01-requirements.md`（功能清单）、`02-data-design.md`（表结构）
> 下游影响：`06-tech-architecture.md`（服务层实现接口）、前端 API 封装

## 文档目标

定义前后端对接的完整契约：通用约定、错误码表、所有端点的请求/响应示例。前端据此封装 API，后端据此实现接口，测试据此编写用例。

## 1. 通用约定

| 项 | 约定 |
|----|------|
| 协议 | HTTPS |
| 方法 | 统一 POST（查询类可 GET） |
| 数据格式 | application/json; charset=utf-8 |
| 认证 | JWT Bearer Token（`Authorization: Bearer <token>`） |
| API 前缀 | `/api/<功能模块>` |
| 统一响应 | `{ "code": 0, "message": "success", "data": {} }` |
| 分页响应 | `{ "code": 0, "message": "success", "data": { "list": [], "total": 0, "page": 1, "pageSize": 20 } }` |
| 时间格式 | ISO 8601（`YYYY-MM-DDTHH:mm:ssZ`） |
| ID 类型 | 字符串（BIGINT 序列化） |

### 统一响应结构

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "<字段>": "<值>"
  }
}
```

### 分页请求参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | number | 否 | 页码，默认 1 |
| pageSize | number | 否 | 每页条数，默认 20 |

## 2. 错误码表

| code | 含义 | 前端处理 |
|------|------|---------|
| 0 | 成功 | 正常处理 |
| 40001 | 参数错误 | 提示参数错误信息 |
| 40100 | 未登录 | 跳转登录页 |
| 40300 | 无权限 | 提示无权限 |
| 40400 | 资源不存在 | 提示资源不存在 |
| 40900 | 业务冲突（如重复提交） | 提示冲突信息 |
| 50000 | 服务器错误 | 提示系统异常 |
