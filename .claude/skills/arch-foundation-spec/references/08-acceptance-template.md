## 2. 质量门 9 项检查

> 阶段 4 implement 代码生成后必须逐项检查，全部通过才允许 git commit。

### 2.1 高优先级（5 项）

| # | 检查项 | 检查方法 | 通过标准 | 修复方法 |
|---|--------|---------|---------|---------|
| 1 | 导航 fail 回退 | 代码搜索 `navigateTo`、`uni.navigateTo` | 所有调用必须有 fail 回调 | 补充 fail 回调，提示用户 |
| 2 | 无静默 catch | 代码搜索 `.catch(`、`try.*catch` | catch 块必须有错误处理（Toast/日志） | 补充错误处理逻辑 |
| 3 | defineProps 规范 | Vue3 组件检查 | 使用类型声明 `defineProps<Props>()` | 改为类型声明方式 |
| 4 | 无 Mock 数据 | 代码搜索 `mock`、`Mock`、`假数据` | 不得残留任何 Mock 数据 | 删除 Mock，接入真实接口 |
| 5 | 无 console 残留 | 代码搜索 `console.log`、`console.warn` | 生产代码不得有 console | 删除 console 语句 |

### 2.2 中优先级（4 项）

| # | 检查项 | 检查方法 | 通过标准 | 修复方法 |
|---|--------|---------|---------|---------|
| 6 | z-index 分层 | 检查所有 z-index 值 | 按规范分层：10/100/1000/2000 | 调整 z-index 到规范值 |
| 7 | 登录跳转统一 | 代码搜索 401 处理 | 统一走 `handleUnauthorized` | 收敛到统一函数 |
| 8 | API 错误提示 | 检查接口错误处理 | 统一走 `showError` 或 `ElMessage.error` | 收敛到统一函数 |
| 9 | 空状态处理 | 列表页检查 | 数据为空时展示 Empty 组件 | 补充 Empty 组件 |

## 3. 测试要点

### 3.1 边界条件

| # | 场景 | 预期结果 |
|---|------|---------|
| 1 | 空数据查询（无记录） | 返回空列表，页面展示 Empty |
| 2 | 分页第 1 页只有 1 条 | 正常展示，分页器显示 1 页 |
| 3 | 输入超长字符串（>255） | 返回参数错误 |
| 4 | 日期选择跨年 | 正常查询 |
| 5 | 金额输入负数 | 返回参数错误 |

### 3.2 异常处理

| # | 场景 | 预期结果 |
|---|------|---------|
| 1 | 网络断开 | 显示网络异常提示，可重试 |
| 2 | 接口返回 500 | 显示系统异常提示 |
| 3 | 接口返回 401 | 跳转登录页 |
| 4 | 接口返回 403 | 显示无权限提示 |
| 5 | 并发提交相同表单 | 第二次提交返回冲突错误 |

### 3.3 并发场景

| # | 场景 | 预期结果 |
|---|------|---------|
| 1 | 两人同时编辑同一条记录 | 后提交者返回冲突，提示数据已变更 |
| 2 | 高并发查询列表 | 响应时间不显著增加 |
| 3 | 批量导入 1000 条 | 全部成功或失败回滚 |

### 3.4 权限场景

| # | 场景 | 预期结果 |
|---|------|---------|
| 1 | employee 查看他人数据 | 返回空或 403 |
| 2 | employee 调用 admin 接口 | 返回 403 |
| 3 | admin 调用 superadmin 接口 | 返回 403 |
| 4 | 未登录访问任意接口 | 返回 401，跳转登录 |
