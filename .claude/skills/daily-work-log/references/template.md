# 工作日报模板

> 对齐《工作日报 PRD》（`大纲/PRD/工作日报/00-index.md`）四字段口径：今日工作内容（必填，≤100 字）/ 明日工作计划 / 遇到的问题 / 需协调事项。
> 「开发补充」段（完成明细 / 部署状态 / 验证结果 / 待处理）为开发内部信息，提报公司日报时删除。

## 标准格式

```markdown
# 工作日报 — YYYY-MM-DD

---

## 今日工作内容

（必填，≤100 字。一句到两句高概括当日核心工作，可点出功能模块；不逐条罗列 commit/文件）

- 完成答题模块四项修复（练习记录清理/Web 选题/部门树/按钮验证）

## 明日工作计划

（选填。从待办 / 下一步任务推导，可执行）

- [ ] 计划项 1
- [ ] 计划项 2

## 遇到的问题

（选填。当日阻塞、异常、未解决 bug，写清现状）

- 问题 1：现状描述

## 需协调事项

（选填。需他人配合 / 领导确认 / 跨部门协调；含「待上传发布 / 待人工验收 / 待产品确认」类）

- 协调 1：事项描述

---

## 开发补充（提报公司日报时删除本段）

### 完成明细

- 事项 1（涉及模块，`xxxxxxx`）｜ 事项 2 …

### 部署状态

| 层 | 状态 | 备注 |
|------|:--:|------|
| 后端 | ✅/❌ | PM2 重启 / 未部署 |
| 小程序 | ✅/❌ | 已构建 / 未构建 |
| Webapp | ✅/❌ | 已构建 / 未构建 |

### 验证结果

- 验证项 1 ✅/❌
- 验证项 2 ✅/❌

### 待处理

- [ ] 待办项 1
- [ ] 待办项 2

---

*自动生成*
```

## 追加格式（当日已有日报时）

在已有文件对应小节中追加当日补充内容（「今日工作内容」只追加仍属当日的新增概括；「明日工作计划 / 遇到的问题 / 需协调事项」与「开发补充」各小节相应更新）。
不要覆盖已有的标题和分隔行（一人一天一条，对应 PRD 规则 2）。
