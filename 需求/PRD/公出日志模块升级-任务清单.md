# 公出日志模块升级 v2.0 — 功能清单

> 汇报日期：2026-06-13 | 当前阶段：PRD 完成，待开发

---

## 级别说明

| 级别 | 含义 |
|:--:|------|
| **P0** | 核心基础 — 缺了系统跑不起来，必须最先完成 |
| P1 | 主要功能 — 上线必备，P0 完成后启动 |
| P2 | 锦上添花 — 可后续迭代优化 |

---

## 一、员工端（小程序）

### 1. 日报填写

| 功能 | 说明 | 级别 |
|------|------|:--:|
| **公出日志** | 外场人员每日填写，含项目、作业人员、机型、工作量等完整字段 | **P0** |
| **补公出日志** | 漏填后补录，需填写补录日期和原因，提交后管理员审核 | **P0** |
| **公司日报** | 办公室人员使用，仅填写工作内容/计划/问题，字段简化 | P1 |
| **三种类型一键切换** | 填写页顶部 Tab 切换：公出日志 / 补公出日志 / 公司日报 | **P0** |
| **工作类型六选一** | 工作（陆）/ 工作（海）/ 待工 / 在途 / 请假 / 调休 | **P0** |
| **请假/调休自动简化** | 选择请假或调休时，自动隐藏项目、人员、工作量等外场字段 | P1 |
| **草稿自动保存** | 填写过程中自动保存草稿，防止数据丢失 | P1 |

### 2. 人员选择

| 功能 | 说明 | 级别 |
|------|------|:--:|
| **花名册搜人选人** | 从花名册搜索人员姓名或工号，勾选即可添加，替代过去手敲人名 | **P0** |
| **同组代填** | 提交时勾选的同组人员，自动标记为"已由 XX 代填"，无需重复提交 | **P0** |
| **已代填提示** | 打开填写页时自动检测，如已被同组人代填则显示提示，避免重复 | P1 |

### 3. 统计看板（新增页面）

| 功能 | 说明 | 级别 |
|------|------|:--:|
| **个人统计卡片** | 展示累计日志数、当月条数、缺失天数、延迟条数四格数据 | P1 |
| **缺失日期列表** | 列出本月哪些日期漏填了日志 | P1 |
| **月度工作占比** | 条形图展示当月工作类型分布（陆/海/待工/在途/请假/调休各占多少） | P1 |
| **同组日志** | 查看同组成员最近 7 天的日志（只读，不可编辑） | P2 |

### 4. 补公出审核状态

| 功能 | 说明 | 级别 |
|------|------|:--:|
| **审核中状态** | 补公出日志提交后显示「审核中」标签，可查看但不可编辑 | P1 |
| **审核结果通知** | 审核通过/驳回时收到推送通知 | P1 |

---

## 二、管理员端（小程序 + Web 后台）

### 1. 人员花名册管理

| 功能 | 说明 | 级别 |
|------|------|:--:|
| **花名册列表** | 查看所有外场人员，含姓名、工号、入场日期、在职/离职状态、累计日志数 | **P0** |
| **新增人员** | 录入姓名、工号、入场日期 | **P0** |
| **编辑/离职/删除** | 修改人员信息、标记离职、删除记录 | **P0** |

### 2. 补公出日志审核

| 功能 | 说明 | 级别 |
|------|------|:--:|
| **待审核列表** | 查看所有待审核的补公出日志，显示提交人、补录日期、项目、原因 | **P0** |
| **审核判定** | 判定「特殊情况」（无法填写，算正常）或「非特殊/忘记」（标记延迟） | **P0** |
| **审核意见** | 填写审核意见（可选） | P1 |

### 3. 日报管理增强

| 功能 | 说明 | 级别 |
|------|------|:--:|
| **日志类型筛选** | 按公出日志 / 补公出日志 / 公司日报筛选 | P1 |
| **工作类型筛选** | 按工作（陆/海）/ 待工 / 在途 / 请假 / 调休筛选 | P1 |
| **作业人员列** | 列表中显示每日志的作业人员名单 | P1 |

### 4. 统计看板（管理层）

| 功能 | 说明 | 级别 |
|------|------|:--:|
| **全员汇总** | 系统总日志数、本月新增、延迟总数、当日缺失人数 | P1 |
| **按项目统计** | 每个项目的日志总量、本月数量、缺失数量 | P1 |
| **按人员统计** | 每个人的日志总量、本月数量、缺失数量、最近提交日期 | P1 |

### 5. 员工当日状态（新增）

| 功能 | 说明 | 级别 |
|------|------|:--:|
| **全员当日一览** | 一张表看所有外场人员今天的状态：谁提交了、谁被代填了、谁请假了、谁还没交 | P1 |
| **七种状态标记** | 已提交 / 补公出 / 公司日报 / 已代填 / 请假 / 调休 / ⚠未提交 | P1 |
| **异常优先排序** | 未提交和已代填的人排在最前面，方便管理者优先关注 | P1 |
| **搜索筛选** | 按姓名/工号搜索，按状态筛选 | P1 |

### 6. 员工月度工作占比（新增）

| 功能 | 说明 | 级别 |
|------|------|:--:|
| **逐人查看** | 选择任意员工和月份，查看其当月工作类型分布 | P1 |
| **六类占比** | 工作（陆）/ 工作（海）/ 待工 / 在途 / 请假 / 调休 各占百分比 | P1 |
| **出勤概览** | 一并展示应出勤天数、已填报天数、缺报天数 | P1 |
| **条形图可视化** | 每类工作用条形图 + 百分比直观展示 | P2 |

## 附：验收标准（11 条）

| # | 条件 |
|:--:|------|
| 1 | 管理员可增删改查外场人员，每个有独立 UID |
| 2 | 日报填写从花名册搜索+多选，不再手敲人名 |
| 3 | A 勾选 B 后，B 当日显示"已由 A 代填"且无法重复提交 |
| 4 | 六个工作类型切换正确，请假/调休时自动隐藏外场字段 |
| 5 | 三个日报 Tab 切换后表单字段正确变化 |
| 6 | 补公出日志审核（特殊/忘记）状态正确更新 |
| 7 | 统计看板累计/当月/缺失/延迟数据正确 |
| 8 | 同组人员可查看彼此日志（只读） |
| 9 | 小程序 + Web 后台 + 后端 API 三端数据一致 |
| 10 | 管理层可查看每个员工当日状态（7 种状态标记） |
| 11 | 管理层可查看每个员工月度工作类型占比（6 类占比） |
