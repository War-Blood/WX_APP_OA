# 公出日志 — 字段规格与看板映射

> 交接文档：仅列出业务字段及字段→图表的对应关系

---

## 一、日志类型

| 类型     | 枚举值                  | 说明             |
| -------- | ----------------------- | ---------------- |
| 公出日志 | `biz_trip`            | 外勤人员每日提交 |
| 补公出   | `biz_trip_supplement` | 漏填补录，需审核 |
| 公司日报 | `office`              | 办公室人员日报   |

---

## 二、业务字段定义

> 表 `daily_reports`，忽略系统字段（id/created_at/updated_at/deleted_at/mood）

### 2.1 通用字段（3 种类型共有）

| 字段              | 中文名       | 类型 | 必填 | 说明                                    |
| ----------------- | ------------ | ---- | ---- | --------------------------------------- |
| `report_date`   | 日志日期     | DATE | ✅   |                                         |
| `report_type`   | 日志类型     | ENUM | ✅   | biz_trip / biz_trip_supplement / office |
| `today_work`    | 今日工作小结 | TEXT | ✅   | office 称"今日工作内容"                 |
| `tomorrow_plan` | 明日计划     | TEXT | ❌   |                                         |
| `remark`        | 备注         | TEXT | ❌   |                                         |

### 2.2 公出/补公出专用字段

| 字段                       | 中文名       | 类型    | 必填  | 说明                                                     |
| -------------------------- | ------------ | ------- | ----- | -------------------------------------------------------- |
| `project`                | 项目名称     | VARCHAR | 条件* | *请假/调休时可不填                                       |
| `area`                   | 项目区域     | VARCHAR | 条件* | 省-市格式                                                |
| `today_work_type`        | 今日工作类型 | VARCHAR | ✅    | 见下方枚举                                               |
| `workers`                | 作业人员     | TEXT    | 条件* | 顿号分隔，填写多人后会传递给多个人，其他人员就无需填写。 |
| `related_party`          | 相关方单位   | VARCHAR | ❌    |                                                          |
| `machine_model`          | 机型         | VARCHAR | ❌    |                                                          |
| `work_content`           | 工作内容     | TEXT    | 条件* | *请假/调休时可不填                                       |
| `required_qty`           | 需求数量     | INT     | 条件* |                                                          |
| `completed_qty`          | 完成数量     | INT     | 条件* |                                                          |
| `entry_date`             | 入场日期     | DATE    | ❌    | 入场填写一次，后续copy                                   |
| `initial_biz_trip_date`  | 初始出差日期 | DATE    | ❌    | 入场填写一次，后续copy                                   |
| `biz_trip_days`          | 项目出差天数 | INT     | ❌    | 通过计算得到（入场到当日）                               |
| `personal_biz_trip_days` | 个人出差天数 | INT     | ❌    | 通过计算得到（出差到当日）                               |
| `tomorrow_work_type`     | 明日工作类型 | VARCHAR | ❌    |                                                          |

### 2.3 补公出专用字段

| 字段                  | 中文名       | 类型 | 必填 | 说明 |
| --------------------- | ------------ | ---- | ---- | ---- |
| `supplement_date`   | 补录目标日期 | DATE | ✅   |      |
| `supplement_reason` | 补录原因     | TEXT | ✅   |      |

### 2.4 公司日报专用字段

| 字段        | 中文名   | 类型 | 必填 | 说明 |
| ----------- | -------- | ---- | ---- | ---- |
| `issues`  | 问题反馈 | TEXT | ❌   |      |
| `content` | 协调事项 | TEXT | ❌   |      |

### 2.5 系统判定字段

| 字段                 | 中文名   | 类型    | 说明                                          |
| -------------------- | -------- | ------- | --------------------------------------------- |
| `status`           | 状态     | VARCHAR | draft → approved / pending_review / rejected |
| `timeliness`       | 及时性   | VARCHAR | on_time / delayed                             |
| `worker_count`     | 作业人数 | INT     | 系统从 workers 计算                           |
| `progress_percent` | 进度%    | DECIMAL | completed_qty / required_qty                  |

### 2.6 工作类型枚举

| 值             | 显示名     |
| -------------- | ---------- |
| `工作（陆）` | 工作（陆） |
| `工作（海）` | 工作（海） |
| `待工`       | 待工       |
| `在途`       | 在途       |
| `请假`       | 请假       |
| `调休`       | 调休       |

## 三、字段 → 看板/图表映射

### 3.1 统计总览卡片

| 指标     | 来源字段                      | 计算方式                  |
| -------- | ----------------------------- | ------------------------- |
| 总日志数 | `id`                        | COUNT(*)，status=approved |
| 本月新增 | `report_date`               | COUNT 本月                |
| 延迟数   | `timeliness`                | COUNT delayed             |
| 缺报人数 | `report_date` + `user_id` | 应报未报人数              |

### 3.2 日历热力图

| 展示                   | 来源字段                      |
| ---------------------- | ----------------------------- |
| X轴=日期, Y轴=提交人次 | `report_date`（按天 COUNT） |

### 3.3 全员当日状态

| 展示                                                   | 来源字段                                                     |
| ------------------------------------------------------ | ------------------------------------------------------------ |
| 状态分类：已提交/被代填/补公出/公司日报/请假/调休/缺报 | `report_type` + `today_work_type` + `status`           |
| 人员明细：姓名、项目、区域、工作类型、提交时间         | `project`, `area`, `today_work_type`, `submitted_at` |

### 3.4 月度工作占比（单人）

| 展示                                  | 来源字段                                |
| ------------------------------------- | --------------------------------------- |
| 6 类工作类型饼图/柱状图（各占多少天） | `today_work_type`（按人+月 GROUP BY） |
| 总提交天数、工作天数、缺报天数        | `report_date` COUNT                   |

### 3.5 人员工作类型分布（全员透视表）

| 展示                             | 来源字段                                              |
| -------------------------------- | ----------------------------------------------------- |
| 行=人员, 列=6类工作类型, 值=天数 | `today_work_type` + `user_id`（按人+月 GROUP BY） |

### 3.6 项目进展看板

| 展示          | 来源字段                                   |
| ------------- | ------------------------------------------ |
| 项目名称      | `project`                                |
| 区域          | `area`                                   |
| 需求/完成数量 | `required_qty`, `completed_qty`        |
| 进度%         | `progress_percent`（completed/required） |
| 日志天数/人次 | `id` COUNT                               |

### 3.7 区域分布（中国地图）

| 展示               | 来源字段                                               |
| ------------------ | ------------------------------------------------------ |
| 省份               | `area`（取 `-` 前段，如 "广东-深圳" → "广东"）    |
| 省份人数           | 该省去重`user_id` 数                                 |
| 下钻人员名单       | `workers` + `user_id` 关联 `users` 表取姓名/工号 |
| **数据范围** | **仅昨日**（`report_date = 昨天`）             |

### 3.8 人员统计看板

| 展示                         | 来源字段                                 |
| ---------------------------- | ---------------------------------------- |
| 姓名、总计、本月数、最后日期 | `user_id` COUNT + MAX(`report_date`) |

### 3.9 补公出审核列表

| 展示                               | 来源字段                                                            |
| ---------------------------------- | ------------------------------------------------------------------- |
| 补录日期、提交人、项目、原因、状态 | `supplement_date`, `project`, `supplement_reason`, `status` |

---

## 四、关键注意

1. **`today_work_type` 归一化**：历史数据中的 "工作"/"作业" → "工作（陆）"，空值 → "工作（陆）"
2. **区域分布仅看昨日**，非月度
3. **统计需去重**：按 `(user_id, report_date)` 去重，防止一人一天多日志重复计数
4. **代填追踪**：`daily_report_workers` 关联表记录被代填人员，被代填者当日状态=substituted
5. **查询某人月度日志**需匹配三种来源：自己提交的 + workers 文本含名 + daily_report_workers 关联
