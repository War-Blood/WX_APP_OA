# 请假/调休日志 — 全流程说明

> 版本: v2.0 | 更新: 2026-06-25

---

## 一、操作流程

```
选择工作类型「请假」或「调休」
    ↓
填写起始日期 + 结束日期 + 备注原因
    ↓
点击「提交」
    ↓
系统自动生成日期范围内每天的日志
```

---

## 二、小程序端（用户侧）

### 2.1 页面变化

| 正常公出日志 | 请假/调休 |
|-------------|----------|
| 项目名称、区域、作业人员、机型、工作内容、工作量 | **全部隐藏** |
| 今日工作小结、明日计划、备注 | **全部隐藏** |
| — | **起始日期、结束日期、备注原因**（新增） |

### 2.2 交互细节

- 日期选择器**无限制**（不限于昨天/今天），可自由选择任意日期
- 备注原因填写到每条日志的 `remark` 字段
- 提交前校验：起始日期 ≤ 结束日期

### 2.3 提交数据

```json
{
  "reportType": "biz_trip",
  "reportDate": "2026-06-25",
  "todayWorkType": "请假",
  "workerIds": [],
  "leaveStartDate": "2026-06-25",
  "leaveEndDate": "2026-06-27",
  "remark": "家里有事"
}
```

---

## 三、后端处理

### 3.1 Controller 校验

1. `todayWorkType` 为「请假」或「调休」→ `isLeaveOrRest = true`
2. 必填校验：`leaveStartDate`、`leaveEndDate` 不为空
3. 逻辑校验：`leaveEndDate >= leaveStartDate`
4. 跳过 project / area / workerIds 的必填校验

### 3.2 Service 批量生成

`batchCreateLeaveLogs` 函数：

```
for 每一天 from leaveStartDate to leaveEndDate:
    ① 查 daily_reports 是否已有该用户+该日期的记录
       → 有 → 跳过，记入 skippedDates
       → 无 → 继续
    ② 查 users 表取 nickname || user_name
    ③ INSERT 一条记录
```

### 3.3 入库数据

| 字段 | 值 |
|------|-----|
| `report_type` | `biz_trip` |
| `project` | `"请假"` 或 `"调休"` |
| `today_work_type` | `"请假"` 或 `"调休"` |
| `workers` | 当前用户姓名 |
| `status` | `approved` |
| `timeliness` | `on_time` |
| `report_date` | 范围内的每一天 |
| 其余字段 | `NULL` |

### 3.4 返回数据

```json
{
  "code": 0,
  "data": {
    "reportId": 1234,
    "created": 3,
    "createdIds": [1234, 1235, 1236],
    "skippedDates": ["2026-06-26"]
  }
}
```

## 四、小程序端（反馈）

### 4.1 成功提示

| 情况 | 提示 |
|------|------|
| 生成 N 天（N>1） | 「已生成 3 天请假记录」 |
| 仅生成 1 天 | 「提交成功」 |
| 有跳过的日期 | 追加「，2026-06-26 已有日志已跳过」 |

### 4.2 后续状态

- 生成的日志状态为 `approved`（已通过），**无需审核**
- 全员当日状态中自动标记为「请假」或「调休」
- 公出统计中计入工作类型分布

## 五、与其他类型的对比

| | 公出日志 | 补公出 | 请假/调休 |
|------|:--:|:--:|:--:|
| 提交后状态 | approved | pending_review | approved |
| 需审核 | 否 | **是** | 否 |
| project 必填 | 是 | 是 | **否**（自动填类型名） |
| workers 必填 | 是 | 是 | **否**（自动填本人） |
| 日期范围 | 单天 | 单天 | **多天** |
| 日期限制 | 昨天/今天 | — | **无限制** |
