小程序端写日报功能做简化处理。将之前的请假整改。

## 请假/调休类型简化

选择「请假」或「调休」后：

### 显示字段（仅2个）

- **作业人员**（多选，必填）
- **备注原因**（选填）

### 项目名默认值

- `project` 默认填写 `"请假"` 或 `"调休"`（与 todayWorkType 一致）

### 其余字段均为 NULL

- area / todayWork / tomorrowPlan / machineModel / workContent / requiredQty / completedQty / entryDate / initialBizTripDate 等全部 NULL

### 日期限制解除

- 日期选择器不再限制「仅昨天/今天」，可自由选择任意日期
- 不允许同一日期多次提交（检查重复）

### 提交数据格式

```json
{
  "reportType": "biz_trip",
  "reportDate": "2026-06-26",
  "todayWorkType": "请假",
  "workerIds": [14, 15],
  "project": "请假",
  "remark": "家里有事"
}
```
