## 1. 布局系统

### 1.1 四层结构

```
┌──────────────────────────────────────────────────────┐
│  顶栏 TopBar (48px)                                    │
│  Logo | 全局搜索 | +新建 | 通知 | 头像下拉               │
├────┬─────────────┬───────────────────────────────────┤
│ 一级 │  二级侧栏      │  主内容区                          │
│ 图标 │  ModuleSidebar │  MainContent                     │
│ 栏   │  (180px)       │                                   │
│56px │               │  ┌─────────────────────────────┐  │
│     │  模块标题       │  │ 页面工具栏                    │  │
│ 仪  │  ──────────    │  │ (搜索/筛选/操作按钮)           │  │
│ 表  │  子菜单1       │  ├─────────────────────────────┤  │
│ 人  │  子菜单2  ←活跃 │  │ 内容区                        │  │
│ 事  │  子菜单3       │  │ (表格/卡片/表单)              │  │
│ 组  │               │  │                               │  │
│ 织  │  ──────────    │  │                               │  │
│ 审  │  快捷操作      │  │                               │  │
│ 批  │               │  └─────────────────────────────┘  │
│ ... │               │                                   │
│ 设  │               │                                   │
│ 置  │               │                                   │
├────┴─────────────┴───────────────────────────────────┤
│  56px    180px           flex: 1                       │
└──────────────────────────────────────────────────────┘
```

### 1.2 尺寸规范

| 区域 | 宽度/高度 | 说明 |
|------|----------|------|
| 顶栏 TopBar | 48px 高 | 全宽，fixed |
| 一级图标栏 PrimaryNav | 56px 宽 | fixed，全高 |
| 二级侧栏 ModuleSidebar | 180px 宽 | fixed，全高（顶栏下方） |
| 主内容区 MainContent | flex: 1 | 自适应剩余宽度 |
| 内容区内边距 | 20px | 卡片间距 16px |
| 卡片圆角 | 8px | 统一 |
| 卡片阴影 | 0 1px 3px rgba(0,0,0,0.06) | 轻微 |

### 1.3 CSS 变量定义

```scss
// 布局尺寸
$topbar-height: 48px;
$primary-nav-width: 56px;
$module-sidebar-width: 180px;
$content-padding: 20px;
$card-gap: 16px;
$card-radius: 8px;
$card-shadow: 0 1px 3px rgba(0, 0, 0, 0.06);

// 布局计算
$layout-offset: calc(#{$topbar-height} + #{$primary-nav-width} + #{$module-sidebar-width});
$content-width: calc(100vw - #{$primary-nav-width} - #{$module-sidebar-width});
```

## 2. 色彩系统

### 2.1 主色板

| 色彩 | 变量 | 色值 | 用途 |
|------|------|------|------|
| 主色 | `$primary` | `#2B6DE8` | 按钮/链接/选中态 |
| 主色浅 | `$primary-light` | `#E6F1FB` | 选中背景/hover |
| 主色深 | `$primary-dark` | `#1A5AD4` | active 态 |
| 成功 | `$success` | `#22C55E` | 成功状态 |
| 警告 | `$warning` | `#F59E0B` | 警告状态 |
| 危险 | `$danger` | `#EF4444` | 删除/错误 |
| 信息 | `$info` | `#909399` | 次要信息 |

### 2.2 中性色板

| 色彩 | 变量 | 色值 | 用途 |
|------|------|------|------|
| 页面背景 | `$bg-page` | `#F5F7FA` | 主内容区背景 |
| 面板背景 | `$bg-panel` | `#FFFFFF` | 卡片/侧栏背景 |
| hover 背景 | `$bg-hover` | `#F0F2F5` | 列表项 hover |
| 选中背景 | `$bg-active` | `#E6F1FB` | 选中项背景 |
| 分隔线 | `$border-light` | `#E4E7ED` | 卡片/区域分隔 |
| 边框 | `$border-base` | `#D3D1C7` | 输入框/表格边框 |

### 2.3 文字色板

| 色彩 | 变量 | 色值 | 用途 |
|------|------|------|------|
| 主要文字 | `$text-primary` | `#303133` | 标题/正文 |
| 常规文字 | `$text-regular` | `#606266` | 次要正文 |
| 辅助文字 | `$text-secondary` | `#909399` | 标签/提示 |
| 占位文字 | `$text-placeholder` | `#C0C4CC` | placeholder |
| 反白文字 | `$text-inverse` | `#FFFFFF` | 深色背景上的文字 |

### 2.4 与现有 OA 系统的差异

| 项目 | OA 现有 | Worktile 风格 | 变更 |
|------|---------|--------------|------|
| 侧栏背景 | `#304156` (深蓝灰) | `#FFFFFF` (白色) | 改为白色 |
| 侧栏文字 | `#BFCBD9` (浅灰) | `#606266` (深灰) | 改为深灰 |
| 选中文字 | `#2B6DE8` (主色) | `#2B6DE8` (主色) | 不变 |
| 选中背景 | 无 | `#E6F1FB` (主色浅) | 新增浅色背景 |
| 顶栏高度 | 60px | 48px | 缩小 |
| 顶栏内容 | 面包屑+用户 | 搜索+通知+头像 | 重新设计 |

## 4. 间距系统

采用 **4px 基准网格**：

| 变量 | 值 | 用途 |
|------|-----|------|
| `$space-xs` | 4px | 图标与文字间距 |
| `$space-sm` | 8px | 紧凑元素间距 |
| `$space-md` | 12px | 表单项间距 |
| `$space-base` | 16px | 卡片内边距/常用间距 |
| `$space-lg` | 20px | 页面内边距 |
| `$space-xl` | 24px | 大区块间距 |
| `$space-xxl` | 32px | 页面顶级间距 |

## 8. 交互模式

### 8.1 模块切换

- 点击一级图标栏 → 二级侧栏内容切换 → 主内容区路由跳转
- 切换动画：侧栏内容淡入淡出 200ms
- 当前模块图标高亮（主色背景）

### 8.2 全局搜索

- 顶栏搜索框，点击或 `Ctrl+K` 聚焦
- 输入时下拉显示搜索结果（用户/项目/任务/日报）
- 结果分类展示，键盘上下选择，回车跳转

### 8.3 新建操作

- 顶栏 `+` 按钮 → 下拉菜单显示可新建的类型
- 根据当前模块上下文智能排序
- 点击后打开对应弹窗

### 8.4 通知

- 顶栏铃铛图标，带红点未读徽标
- 点击下拉显示最近 10 条通知

## 9. 动画规范

| 动画 | 时长 | 缓动 | 场景 |
|------|------|------|------|
| 模块切换 | 200ms | ease-out | 侧栏内容淡入 |
| 弹窗打开 | 250ms | ease-out | dialog scale + fade |
| 弹窗关闭 | 200ms | ease-in | dialog scale + fade |
| 下拉菜单 | 150ms | ease-out | dropdown 展开 |
| 表格行 hover | 100ms | ease | 背景色变化 |
| 按钮 hover | 100ms | ease | 背景色/阴影变化 |
| 页面切换 | 200ms | ease-out | router-view fade |

```scss
// 动画变量
$transition-fast: 100ms ease;
$transition-base: 200ms ease-out;
$transition-slow: 250ms ease-out;

// router-view 过渡
.fade-enter-active, .fade-leave-active {
  transition: opacity $transition-base;
}
.fade-enter-from, .fade-leave-to {
  opacity: 0;
}
```
